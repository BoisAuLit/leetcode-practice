# 垃圾 / 可忽略题（备战期间不看）

这里的题满足**两个条件**才被移进来，确保不误伤经典：
1. **不在 NeetCode 150 / Blind 75** 等任何标准面试清单上；且
2. 是**纯 trick 的数字/字符串小题**，或**冷门 LeetCode 周赛题**（编号多为 2xxx–3xxx）。

## 为什么忽略
- 这些题的解法是"想到一个 trick 就秒、想不到也学不到可迁移的模式"，或者根本不会出现在真实面试里。
- 备战期精力有限，复习它们是用稀缺时间换低频知识。**做过即可，永不复习。**

## 移进来的类别
- 纯数字 trick：Strobogrammatic、Add Digits、Ugly Number、Power of Three/Four、Valid Perfect Square、Reordered Power of 2、Complement Base 10、Sign of Product……
- 日期/字符串小题：Hexspeak、Days Between Dates、Check Straight Line……
- 一次性 easy 统计题：Good Pairs、Richest Customer、Max Population Year、Running Sum、Matrix Diagonal Sum、Parking System……
- 冷门周赛题：2038/2100/2214/2221/2222/2245/2305/2340/2357/2483/2609/2696/2748/2870/3025/3071/3085/3443……
