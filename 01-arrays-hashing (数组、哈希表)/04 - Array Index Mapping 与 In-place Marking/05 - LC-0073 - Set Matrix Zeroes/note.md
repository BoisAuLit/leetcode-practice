# Set Matrix Zeroes 笔记（2026-09-10）

信号→模式："就地修改矩阵，且修改的触发条件依赖矩阵自身内容 → 读写分离两阶段（先侦察记录，后统一动手），防止自己写的值污染判断。"

这个模式不止这一题——凡是"边遍历边改、改的又是判断依据"的题（生命游戏 289 是它的亲兄弟），第一反应都是拆成两阶段。

守卫：
- `[[1,2,3],[4,0,5],[6,7,8]] → [[1,0,3],[0,0,0],[6,0,8]]`（中心 0，验证无连锁反应）
- `[[0,1],[1,1]] → [[0,0],[0,0]]`（0 在记事本区，专杀 O(1) 版的顺序错误）

## O(1) 空间版的四步顺序

1. 先备份第 0 行 / 第 0 列自己原本有没有 0（它们即将被征用做记事本）。
2. 扫内部区域 (1,1) 起，发现 0 就在行头、列头打标记。
3. 按记事本清零内部区域，不碰记事本自己。
4. 最后才处理第 0 行 / 第 0 列。顺序反了记事本先被抹掉，内部就没依据了。
