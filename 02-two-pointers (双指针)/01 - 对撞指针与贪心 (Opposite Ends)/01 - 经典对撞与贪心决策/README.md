# 01 - 经典对撞与贪心决策

**01 LC-0167 → 02 LC-0011 → 03 LC-0042 → 04 LC-0881 → 05 LC-0633**

这五道题共用同一个骨架，区别只在「凭什么敢丢掉这一侧」：

| 题 | 丢弃的理由 |
|---|---|
| 0167 | 数组有序 ⇒ 和偏小时，右端已是最大，左端非动不可 |
| 0011 | 移长边宽度减小而高度仍受短边限制 ⇒ 不可能更优 |
| 0042 | 矮侧的瓶颈已由对面保证 ⇒ 可以当场结算 |
| 0881 | 最重的人必须占一条船 ⇒ 顺带捎上最轻的不会变差 |
| 0633 | 候选空间 `0..⌊√c⌋` 虚拟有序 ⇒ 同 0167 |

## LC-0042 为什么放在这里（而不是单调栈专题）

它原来在 `18-monotonic-fuck-you/monotonic-stack`，现已按主算法归属搬到本目录。
理由：**面试要的是 O(1) 空间的对撞指针解法**，而且这道题现有的第一个解法本来就是
前后缀最大值数组，不是单调栈。单调栈版作为 `Solution_3` 保留在同一个文件里。

```python
l, r = 0, len(height) - 1
left_max = right_max = 0
water = 0
while l < r:
    if height[l] < height[r]:          # ! 矮的那一侧决定了这一格能存多少水
        left_max = max(left_max, height[l])
        water += left_max - height[l]   # 不变量：left_max 就是 l 左边的最高墙
        l += 1
    else:
        right_max = max(right_max, height[r])
        water += right_max - height[r]
        r -= 1
```

**为什么这样是对的**：第 i 格的水量 = `min(左边最高, 右边最高) - height[i]`。
当 `height[l] < height[r]` 时，右边必然存在一面高度 >= `height[r]` > `height[l]` 的墙，
所以 **l 这一格的瓶颈一定在左边**，`left_max` 已经是它的最终答案，可以当场结算，
完全不需要知道右边具体有多高。这和 LC-0011 移短边是同一个论证。

三种解法的复杂度对照：前后缀最大值数组 O(n)/O(n)、**双指针 O(n)/O(1)**、单调栈 O(n)/O(n)
（横着按层结算，和 LC-0084、LC-0739 共用模板）。

## 易错点

- 0011 移长边、0042 移高边都会得到错误答案，而小数据常常看不出来。
- 0042 结算用 `left_max - height[l]`，`left_max` 必须**先用当前高度更新过**，否则会出负数。
- 0881 的循环条件是 `l <= r`（只剩一个人也要一条船），其余四题是 `l < r`。
