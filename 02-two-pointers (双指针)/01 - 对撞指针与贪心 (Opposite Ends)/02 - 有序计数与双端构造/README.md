# 02 - 有序计数与双端构造

**01 LC-0977 → 02 LC-0611**

两道题代表对撞指针的另外两种用法：**倒着构造结果**，和**一次比较批量计数**。

## LC-0977：从两端取较大者，倒着填

平方之后最大值一定在两端（最负的或最正的），所以从结果数组的**末尾**往前填。
正着填会覆盖还没读到的数据 —— 和 LC-0088 从末尾合并是同一个道理。

## LC-0611：一次比较批量计数

它原来在 `05-binary-search/answer-space`，现已按主算法归属搬到本目录
（二分版作为 `Solution_1` 保留，`Solution_3` 才是本目录要练的对撞指针版）。

```python
nums.sort()
cnt = 0
for k in range(len(nums) - 1, 1, -1):      # 固定最大边 nums[k]
    i, j = 0, k - 1
    while i < j:
        if nums[i] + nums[j] > nums[k]:    # ! i..j-1 配 j 全都成立
            cnt += j - i                   # 一次加 j-i 个，不要逐个枚举
            j -= 1
        else:
            i += 1
```

**决定性观察**：排序后只需验证 `较小两边之和 > 最大边`（另两个不等式自动成立）。
**为什么能批量计数**：若 `nums[i] + nums[j] > nums[k]`，那么把左指针换成任何
`i' ∈ [i, j-1]` 都有 `nums[i'] >= nums[i]`，和同样 > `nums[k]`，所以一次加 `j - i`。

这个「**满足条件就一次加一段**」的模式和 LC-0259 - 3Sum Smaller 完全一样，
是双指针用于**计数**（而不是找一组解）时的统一手法。

## 易错点

- 计数是 `j - i` 不是 `j - i + 1`（j 自己已经被当成第二条边用掉了）。
- `nums[i] == 0` 要跳过：0 不能作为三角形的边。
- 0977 正着填结果数组会覆盖未读数据。
