# 02 - K-Sum 系列 (K-Sum)

## 算法定义

**排序 + 固定 k-2 个数 + 剩下两个用对撞指针**。K-Sum 不是新算法，而是 Level 01 外面套循环：
2Sum 是基础，3Sum 固定一个，4Sum 固定两个。时间复杂度规律 `O(n^(k-1))`，排序被吸收。

## Pointer Movement Rules

内层永远是同一件事：和偏小移左、偏大移右、命中则两端同时内移并跳过重复。

## Loop Invariants

1. 数组有序，`nums[i]` 是本轮固定的最小元素，`[l, r]` 是剩余候选区间。
2. 已输出的组合互不相同 —— 这条**完全依赖去重逻辑**，是本家族唯一的难点。

## 必备模板（去重的两处都不能漏）

```python
nums.sort()
for i in range(n - 2):
    if i and nums[i] == nums[i - 1]:      # ! 外层：同一个值作为最小元素只枚举一次
        continue
    l, r = i + 1, n - 1
    while l < r:
        s = nums[i] + nums[l] + nums[r]
        if s == 0:
            res.append([nums[i], nums[l], nums[r]])
            l += 1
            r -= 1
            while l < r and nums[l] == nums[l - 1]:   # ! 内层：命中后跳过重复
                l += 1
            while l < r and nums[r] == nums[r + 1]:
                r -= 1
        elif s < 0:
            l += 1
        else:
            r -= 1
```

**为什么外层用 `nums[i] == nums[i-1]` 而不是 `nums[i] == nums[i+1]`**：前者表示
「这个值作为最小元素已经枚举过」，后者会把 `[-1,-1,2]` 这种合法答案跳掉。

## 最容易出错的地方

- **去重只写了一处**。外层漏了会输出重复组合，内层漏了同样会。
- 0016 不需要去重（只求一个最接近值），很多人照抄 0015 的去重反而把答案跳掉。
- 0259 的计数：条件成立时 `l` 配 `l+1..r` 全部成立，一次加 `r - l`，别在里面再套循环。
- 4Sum 在 C++/Java 里要注意整数溢出（Python 没这问题）。

## 与相邻家族的区别

- **Level 01**：没有外层循环的 K-Sum。
- **LC-0454 4Sum II**（在 `01-arrays-hashing`）：四个**独立数组**各取一个数，
  用哈希表折半配对 O(n²)，和本家族的排序 + 对撞完全不同，不要混。
- **不要去背通用递归 kSum 框架**。能当场从 2Sum 推到 3Sum 再推到 4Sum 就够了。
