# 02 - 中心扩展 (Expand Around Center)

**01 LC-0005 → 02 LC-0647**

两道题原来以 NeetCode 版本放在 `12-dynamic-programming/string-dp`，现已按主算法归属搬来：
它们现有的解法**本来就是中心扩展**，不是 DP。区间 DP 版作为 `Solution_2` 保留在各自文件里。

## 为什么有 2n-1 个中心

一个回文由它的中心唯一决定，而中心有两种：

- **奇数长度**：中心是一个字符，共 n 个（`i = 0..n-1`）
- **偶数长度**：中心是两个相邻字符之间的缝，共 n-1 个（`i, i+1`，`i = 0..n-2`）

合起来 `n + (n-1) = 2n-1` 个候选中心。漏掉偶数中心是这类题最常见的错误 ——
`"abba"` 的答案就落在缝上。

## 模板（两题共用，只改最后怎么收集答案）

```python
def expand(s, l, r):
    while l >= 0 and r < len(s) and s[l] == s[r]:
        l -= 1
        r += 1
    return l + 1, r - 1            # ! 回退一步，返回闭区间 [左, 右]

# LC-0005：取最长
best = (0, -1)
for i in range(len(s)):
    for l, r in (expand(s, i, i), expand(s, i, i + 1)):   # 奇中心 + 偶中心
        if r - l > best[1] - best[0]:
            best = (l, r)
s[best[0]:best[1] + 1]

# LC-0647：改成计数，一个中心扩展 k 次就贡献 k 个回文
total = 0
for i in range(len(s)):
    for l, r in ((i, i), (i, i + 1)):
        while l >= 0 and r < len(s) and s[l] == s[r]:
            total += 1
            l -= 1
            r += 1
```

**循环不变量**：每次进入 while 时 `s[l:r+1]` 已经是回文；扩展一步后两端字符相等，
所以它仍然是回文。失败时回退一步得到的就是以这个中心能取到的最长回文。

**0647 为什么不会重复计数**：每个回文子串的中心唯一确定（长度的奇偶决定是字符还是缝），
所以每个子串只会在它自己的那个中心被数到一次。

## 和 Level 04/01（LC-0125 / 0680）的区别

那两题是**给定区间验证**回文（指针从两端向内收），这里是**枚举中心向外扩**
（指针从内向两端走）。方向相反，不要混。

## 不需要额外记 DP 版本

`dp[i][j] = s[i]==s[j] and dp[i+1][j-1]` 时间同为 O(n²)，空间却要 O(n²)，
而且必须按长度递增填表，顺序容易写错。中心扩展空间 O(1)，面试写它。
Manacher 的 O(n) 属于竞赛技巧，面试提一句名字即可。
