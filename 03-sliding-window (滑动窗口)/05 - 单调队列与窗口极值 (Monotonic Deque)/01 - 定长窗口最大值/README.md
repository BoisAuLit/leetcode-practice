## 为什么需要单调队列

窗口的和可以 O(1) 增量维护，**极值不行**：移除当前最大值之后，
新的最大值是谁？一个标量里恢复不出来。所以要额外保存「未来还可能成为极值的候选」。

## 四个必须答出来的点

1. **为什么存下标而不是值** —— 只有下标才能判断元素有没有离开窗口（`dq[0] <= right - k`）。
2. **为什么能删已离开窗口的队首** —— 它已经不在 `[right-k+1, right]` 里，不可能再是答案。
3. **为什么新值能淘汰队尾较小的元素** —— 队尾那些 `<= x` 的元素**比 x 小、又比 x 先离开窗口**，
   在任何未来的窗口里都不可能成为最大值。这是整个数据结构的灵魂。
4. **为什么队首始终是窗口最大值** —— 由不变量保证：队列里下标递增、对应值单调不增，
   且队首下标在窗口内。

## 模板

```python
from collections import deque
dq, ans = deque(), []
for right, x in enumerate(nums):
    while dq and nums[dq[-1]] <= x:
        dq.pop()                   # ! 队尾：更小又更老，永远出局
    dq.append(right)
    if dq[0] <= right - k:
        dq.popleft()               # ! 队首：已经离开窗口
    if right >= k - 1:
        ans.append(nums[dq[0]])
```

## 复杂度为什么是 O(n)

内层有 while，但**每个下标最多入队一次、出队一次**，所以总的弹出次数不超过 n。
这是摊还分析（amortized analysis），不是「每轮 O(k)」。
