# Level 1 · 01 基础栈、括号与消除 (Stack Fundamentals)

## 核心定义
栈保存「**尚未处理完、将来可能被抵消或恢复**的状态」。
LIFO 之所以合适，是因为现实中的嵌套结构天然满足「最近打开的最先关闭」。

## 决定性观察
1. **嵌套 ⇒ LIFO**：`([{}])` 里最内层最先闭合，这正是栈的语义。
2. **抵消会连锁**：删掉一对之后，原本不相邻的两个元素变成相邻 —— 栈天然处理，
   不需要反复扫描整个字符串。
3. 需要位置信息（哪一段有效、删哪个下标）时，**栈里存下标而不是字符**。

## Loop Invariant
栈里是「已读入但尚未被匹配 / 抵消」的元素，自底向上就是它们出现的先后顺序。

## Push / Pop 规则
- **匹配型**（20、1249）：遇到闭合符号就试着弹出对应的开符号，不匹配立刻失败。
- **抵消型**（1047、1544）：`cancel(stack[-1], c)` 为真就弹，否则压。
- **模拟型**（735、946）：弹不弹由题目的物理规则决定，可能连弹多次。

## 正确性
栈顶永远是「离当前位置最近的、还没被处理的元素」。
所有这些题的规则都只涉及「当前元素和最近的未处理元素」，所以栈顶就是全部所需信息。

## 模板
```python
# 匹配
pairs, stack = {')':'(', ']':'[', '}':'{'}, []
for c in s:
    if c in pairs:
        if not stack or stack.pop() != pairs[c]: return False
    else: stack.append(c)
return not stack

# 抵消（换 cancel 就是另一道题）
stack = []
for c in s:
    if stack and cancel(stack[-1], c): stack.pop()
    else: stack.append(c)
```

## LC-0020 vs LC-0032（不要混）
- **20** 问「**是否**合法」→ 一旦不匹配立刻 `False`。
- **32** 问「最长的**连续合法区间**有多长」→ 不能中途退出，要用下标算长度。
  技巧：栈底先放一个 `-1` 当哨兵，表示「上一个不合法位置」；
  弹栈后若栈空，就把当前下标压进去当新的哨兵。
  LC-0032 也能用 DP 做（12-dynamic-programming 有一份 DP 版副本），本专题讲 Stack 版。

## 常见错误
- LC-0020 忘记最后判断 `not stack`（`"((("` 会被误判成合法）。
- LC-0032 忘了哨兵，或者弹栈后没有处理「栈空」的情况。
- LC-0735 把相撞条件写反（只有 `栈顶 > 0 > 当前` 才撞）；漏掉「同归于尽」。
- LC-1544 抵消谓词漏掉 `a != b`，把 `"aa"` 误删。
- LC-0071 把 `..` 在根目录下的行为写错（栈空时忽略，不能报错）。

## 复习时的 Pattern Recognition
> 「括号是否合法 / 删最少使其合法 / 最长合法段」「相邻的 X 和 Y 会抵消」
> 「按规则模拟一串碰撞或入出栈」 → 基础栈，不要上单调栈。
