# Level 1 · 07 低优先级与跨专题存档 (Archive)

## 这个 Level 1 的用途
保留原有学习成果，但**不让偏门题占据核心学习路线**。
这里的题全部标 **P2**：值得读懂，不值得反复默写。

## 题目

### 01 - 简单括号计数与特殊贪心

**LC-1021 Remove Outermost Parentheses**（P2）
用一个 **Depth Counter** 就够了，**不需要真的维护栈**：
`depth > 0` 时才把字符写进结果，遇到 `(` 先判断再 `+1`，遇到 `)` 先 `-1` 再判断。
它的价值是提醒你：**括号题 ≠ 必须用栈**，很多时候一个计数器就能表达嵌套深度。

**LC-1717 Maximum Score From Removing Substrings**（P2）
Greedy + Stack-based Removal。关键观察：**先删分数高的那种子串**一定不亏
（删 "ab" 和删 "ba" 互不冲突 —— 先删高分的不会让低分的可删次数减少）。
实现上扫两遍，每遍用一个栈做相邻抵消。
它和 LC-1047 的区别：不是无条件抵消，而是**带收益的、有顺序的**抵消。

### 02 - 复杂表达式解析

**LC-0736 Parse Lisp Expression**（P2）
嵌套作用域解析 + 变量绑定 + 环境（Environment）管理。
比 LC-0224 / LC-0394 多出来的是**作用域链**：
内层 `let` 的变量会遮蔽外层同名变量，退出作用域时要恢复。
这是解释器实现的入门，但作为面试模板的性价比很低 —— **不要求背诵**。
当前只要求能看懂已有实现。

### 03 - DP 与时间队列

**LC-2327 Number of People Aware of a Secret**（P2）
**更合适的主归属是 Dynamic Programming / Time-based Simulation**，不是基础队列题。
`dp[i]` = 第 i 天**新学会**秘密的人数，转移是一个固定长度的滑动求和区间
（`delay` 天后开始分享，`forget` 天后忘记）。
可以用队列维护这个区间，也可以用前缀和，**但它不是队列模板题**。
如果以后要重新归类，它应该去 12-dynamic-programming。
