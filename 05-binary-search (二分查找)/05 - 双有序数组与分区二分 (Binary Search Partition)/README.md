# Level 1 · 05 双有序数组与分区二分 (Binary Search Partition)

## 核心定义
不在「值」上二分，而是在**分区位置（Partition）**上二分：
把两个有序数组各切一刀，使左半整体 <= 右半整体。

## 题目：LC-0004 Median of Two Sorted Arrays（P1，Hard）

> 本题原本只有 `NC - Median of Two Sorted Arrays`，已正式化为 `LC-0004`，
> 用户原有的实现**一字未改**地保留为 `Solution_1`。

## 决定性观察
1. 中位数的本质是「把合并后的序列切成左右两半」，要求：
   - 左半元素个数 = `(m + n + 1) // 2`
   - 左半每个元素 <= 右半每个元素
   找到这个切法，答案 O(1) 算出，**根本不需要真的合并**。
2. **两个切点不独立**：A 里切了 i 个，B 里就必须切 `half - i` 个。
   只有一个自由变量 ⟹ 可以二分。
3. 判据只有两条（交叉比较）：
   ```
   Aleft <= Bright   且   Bleft <= Aright
   ```
   - `Aleft > Bright` ⟹ A 切多了 ⟹ 往左移
   - `Bleft > Aright` ⟹ A 切少了 ⟹ 往右移

## 为什么只在较短的数组上二分
切点 `j = half - i` 必须落在 `[0, len(B)]` 内。
若在较长数组上二分，j 会越界，还要额外处理。
先 swap 保证 `len(A) <= len(B)`，j 自动合法 ——
顺带把复杂度从 O(log(m+n)) 改进到 **O(log(min(m, n)))**。

## ±infinity 哨兵
切点在最左（`i == 0`）时没有 Aleft，用 `-inf`（「永远 <= 任何数」）；
切点在最右（`i == len(A)`）时没有 Aright，用 `+inf`。
**有了哨兵，空数组和所有边界切点都不需要单独写分支** —— 这是本题最漂亮的地方。

## 奇偶处理
`half = (m + n) // 2`：
- 总长奇数 → 中位数 = `min(Aright, Bright)`
- 总长偶数 → 中位数 = `(max(Aleft, Bleft) + min(Aright, Bright)) / 2`

## 复杂度
**O(log(min(m, n)))** 时间，O(1) 空间。
对照：合并后取中位数是 O(m + n) 时间 / O(m + n) 空间 —— 面试里可以先给这版再被追问。

## 为什么标 P1 而不是 P0
它是 Hard，边界细节多，**不适合在入门阶段硬背**。
先把 Level 1 的 01–03 全部吃透（尤其是 Lower Bound 的不变量），
再回头看这道题会轻松很多。

## 边界清单（solution.py 里已全部随机对拍验证）
- 其中一个数组为空
- 两个数组值域完全不重叠（`[1,2]` 和 `[100,200]`）
- 含大量重复元素
- 总长为奇 / 偶
- 长度相差悬殊
