## 01 - 其他链表设计与特殊结构

### LC-0353 Design Snake Game（P2）
**主要不是链表题。** 它的核心是
**Deque（蛇身）+ Hash Set（快速判断是否撞到自己）+ 模拟**。
用 deque 是因为蛇头入、蛇尾出，正好是两端操作。
关键细节：**先把尾巴移走再判断是否撞自己**，否则蛇头移到原来尾巴的位置会被误判为撞身。
它更接近 [04-stack-queue](<../../04-stack-queue (栈、队列)/>) 的内容。

### LC-0708 Insert into a Sorted Circular Linked List（P2）
循环有序链表插入。难点全在**边界枚举**，一共要处理三种情况：
1. **普通位置**：`prev.val <= insertVal <= cur.val`。
2. **跨越最大值与最小值的接缝**：`prev.val > cur.val`（这就是环的「断点」），
   此时若 `insertVal >= prev.val`（比最大还大）或 `insertVal <= cur.val`（比最小还小），都插这里。
3. **全链等值 / 转了一整圈都没找到位置**：插在任意位置即可 —— 必须用
   「回到起点就停」作为循环终止条件，否则**死循环**。
还要单独处理 `head is None`（新建一个自环节点）。

### LC-1721 Swapping Nodes in a Linked List（P2）
**标准题意只要求交换节点的 `val`**，不要求真正重连两个节点。
所以用「固定间距双指针找到正数第 k 和倒数第 k，交换 val」就够了，一趟搞定。
**不要把它误教成必须做复杂的 Pointer Rewiring** —— 真要换节点会涉及
「两个节点相邻 / 是同一个 / 其中一个是头」等一堆退化情况，那是另一道（更难的）题。
如果面试官明确要求换节点，再讨论那些边界。

## 02 - 跨专题结构与状态循环

### LC-0109 Convert Sorted List to Binary Search Tree（P2）
Linked List + Binary Tree + Divide and Conquer。
- **朴素做法**：转成数组，然后用标准的「取中点当根、递归左右」，O(n) 时间 O(n) 空间。
- **进阶做法**：中序遍历模拟 —— 先递归构造左子树，此时链表指针正好走到根的位置，
  取值后继续构造右子树。O(n) 时间、O(log n) 栈空间，**不需要额外数组**。
  这个「中序遍历的顺序 == 链表的顺序」的洞察很漂亮。

与 [07-trees (树)](<../../07-trees (树)/>) 的树构造专题关联很强，
本目录保留原有资料，标 P2。

### LC-0957 Prison Cells After N Days（P2）
**不是普通的链表环检测，不要套 LC-0141 的代码。**
它是**有限状态的周期检测**：状态只有 2^8 = 256 种（实际因为首尾恒为 0 更少），
所以序列必然进入循环。
主流做法是用 **Hash Map 记录「状态 → 第几天第一次出现」**，
发现重复就算出周期，然后 `n = (n - first) % cycle` 直接跳过去。
理论上也能用 Floyd，但这里 Hash Map 更直观、也更容易算出「还要再走几步」。
