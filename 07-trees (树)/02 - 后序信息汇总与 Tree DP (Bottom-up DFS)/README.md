# Level 1 · 02 后序信息汇总与 Tree DP (Bottom-up DFS)

## 核心定义
**先算完孩子，再汇总到父亲**。整章只回答一个问题：
### `dfs(node)` 该返回什么，才能让父亲用得上？

## 决定性观察（本专题最重要的一条）
> **递归的返回值 ≠ 最终答案。**

- **返回值**：给父亲用的东西，必须满足「父亲能继续往上拼」的格式。
- **答案**：在每个节点处单独结算，可以用上比返回值更多的信息。

两个经典例子：

| 题 | 返回给父亲 | 在当前节点结算的答案 |
|---|---|---|
| LC-0543 Diameter | 子树高度 `1 + max(l, r)` | `l + r`（**两侧一起**） |
| LC-0124 Max Path Sum | 单向收益 `val + max(l, r, 0)` | `val + max(l,0) + max(r,0)`（**两侧一起**） |

**为什么返回值只能选一侧**：返回的是「从我往上走的一条路径」，
路径不能分叉 —— 父亲接上来之后必须还是一条链。
而答案允许「以当前节点为最高点、左右各伸一条」的 Λ 形路径，所以能用两侧。

## LC-0124 的三个细节
1. `max(0, gain)`：某一侧收益为负时**宁可不要**（接一段负的只会更差）。
2. **全负数树**也必须正确 —— 答案应该是那个最大的（负）节点值，
   所以 `best` 的初值要是 `-inf`，不能是 0。
3. 返回值必须是 `node.val + max(left_gain, right_gain)`（已经各自 clamp 过 0）。

## LC-0337 的多状态返回
```python
def dfs(node) -> (rob, skip):
    rob  = node.val + l.skip + r.skip
    skip = max(l.rob, l.skip) + max(r.rob, r.skip)   # ★ 是 max，不是直接取 rob
```
**为什么必须返回两个值**：只返回「这棵子树的最大收益」的话，
父亲不知道「孩子到底被选没被选」，就无法判断自己能不能选。
这是「单个返回值信息不足 ⟹ 返回元组」的标准范例。

和数组版打家劫舍（LC-0198 / LC-0213）的关系：
**状态定义完全一样**，只是递推的拓扑从「一条链」变成「一棵树」。
想不清楚时，把树退化成只有左孩子的链来对照。

## LC-0110 的单次 DFS 技巧
朴素写法「每个节点都调一次 height()」是 O(n²)。
正确做法：让 `dfs` 同时返回高度**和**是否平衡 ——
用 `-1` 当 sentinel 表示「这棵子树已经不平衡了」，一旦出现就一路往上传。
```python
def h(node):
    if not node: return 0
    l = h(node.left)
    if l == -1: return -1
    r = h(node.right)
    if r == -1 or abs(l - r) > 1: return -1
    return 1 + max(l, r)
```
O(n) 时间。这也是「用返回值编码额外信息」的一个例子。

## LC-0222 的优化依赖完全二叉树
普通计数是 O(n)。利用**完全二叉树**的性质可以做到 O(log²n)：
一路向左得到左高、一路向右得到右高，相等说明是满树，直接 `2^h - 1`；
否则递归左右子树。**这个优化只在完全二叉树下成立**，必须说清楚前提。

## 题目

| # | 题 | 优先级 | 返回什么 |
|---|---|---|---|
| 01/01 | LC-0110 Balanced Binary Tree | P0 | 高度，用 -1 表示不平衡 |
| 01/02 | LC-0543 Diameter of Binary Tree | P0 | 高度；答案是 `l + r`（**边数**，不是节点数） |
| 01/03 | LC-0222 Count Complete Tree Nodes | P1 | 节点数；可用完全树性质优化 |
| 02/01 | LC-0124 Binary Tree Maximum Path Sum | P0 | 单向最大收益 |
| 02/02 | LC-0337 House Robber III | P1 | **元组** `(rob, skip)` |

## 常见错误
- LC-0543 把直径算成节点数（应该是**边数** = `l + r`）。
- LC-0124 忘了 `max(0, gain)`，或者 `best` 初值设成 0 导致全负数树答案错。
- LC-0124 返回值里用了两侧（变成分叉路径，父亲没法接）。
- LC-0337 的 `skip` 直接取孩子的 `rob`（应该是 `max(rob, skip)`）。
- LC-0110 对每个节点重新算高度 ⟹ O(n²)。

## 复习时的 Pattern Recognition
> 「这棵子树的高度 / 直径 / 最大收益 / 节点数」
> 「选了父亲就不能选孩子」
> → Bottom-up。先写清楚**返回值的语义**，再写答案怎么结算。
