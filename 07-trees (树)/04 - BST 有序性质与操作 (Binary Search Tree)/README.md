# Level 1 · 04 BST 有序性质与操作 (Binary Search Tree)

## 核心定义 —— BST 不变量
> 对**任意**节点：**整棵**左子树的值 < node.val < **整棵**右子树的值。

注意「**整棵**」两个字。只检查「当前节点和它的直接左右孩子」是 LC-0098 的头号错解。

两个直接推论，整章都建立在它们之上：
1. **中序遍历 = 升序** ⟹ LC-0230（第 k 小）、LC-0173（迭代器）、LC-0098（中序递增校验）。
2. **一次比较能排除整棵子树** ⟹ LC-0700（搜索）、LC-0235（LCA）、LC-0938（范围求和）。

## 四类操作

### ① 搜索与剪枝
```python
cur = root
while cur and cur.val != val:
    cur = cur.left if val < cur.val else cur.right    # 一次比较砍掉一侧
```
LC-0938 把它升级成**区间剪枝**：
`node.val < low` ⟹ 整棵左子树都没用；`node.val > high` ⟹ 整棵右子树都没用。

### ② 验证（LC-0098）—— 必须用上下界
```python
def valid(node, lo, hi):
    if not node: return True
    if not (lo < node.val < hi): return False
    return valid(node.left, lo, node.val) and valid(node.right, node.val, hi)
valid(root, float('-inf'), float('inf'))
```
**反例**（说明为什么局部检查不够）：
```
      5
     / \
    1   6
       / \
      4   7      ← 4 < 5，但它在 5 的右子树里，不是合法 BST
```
只看每个节点和它的直接孩子，这棵树会被误判为合法。

等价做法：**中序遍历必须严格递增**（用一个 `prev` 变量边走边比）。

### ③ 顺序统计（LC-0230）
中序走到第 k 个就返回 —— 可以**提前退出**，不必遍历整棵树。
最优雅的实现是直接复用 LC-0173 的迭代器调 k 次 `next()`。

### ④ 增删（LC-0701 / LC-0450）

| | 插入 | 删除 |
|---|---|---|
| 落点 | 永远是**叶子** | 可能是任意内部节点 |
| 难度 | 简单，不动已有结构 | 要给「两个孩子」的节点找**替身** |
| 替身 | — | **中序后继**（右子树最左）或**中序前驱**（左子树最右） |

删除的三种情况：
1. 叶节点 → 直接删（返回 None）
2. 只有一个孩子 → 孩子顶上（返回它）
3. 两个孩子 → 用替身的值覆盖当前节点，再**递归删掉那个替身**
   （替身必然没有一侧孩子，所以这次递归一步就结束）

**为什么替身保持不变量**：中序后继是「所有比当前大的值里最小的」，
放到当前位置后，左子树仍全小于它、右子树（去掉它后）仍全大于它。

统一契约：`delete(node, key)` 返回「删除后这棵子树的新根」，
父亲用 `node.left = delete(node.left, key)` 重新接线。
**这个「返回新子树根」的套路，插入和删除共用。**

## LC-0173 迭代器：惰性 vs 预先展开

| | 惰性（栈保存最左路径） | 预先中序进数组 |
|---|---|---|
| 空间 | **O(h)** ← 题目要求 | O(n) |
| next | 摊还 O(1)（单次最坏 O(h)） | O(1) |
| 能否提前停 | 能（和 LC-0230 配合很好） | 已经全算完了 |

**栈顶永远是下一个该返回的节点**，因为它是未访问部分中最左的。
`next()` 弹出栈顶后，把它右子树的「一路向左」路径压进去。

摊还说明：n 次调用总共只把每个节点压入/弹出各一次 ⟹ 总 O(n) ⟹ 摊还 O(1)。
**不能不加说明地说单次 O(1)。**

## LC-0235 vs LC-0236（必考对照）

| | LC-0235（BST） | LC-0236（一般二叉树） |
|---|---|---|
| 依据 | **值域**：p、q 都小就往左，都大就往右，分叉点即 LCA | 无序，只能靠**结构** |
| 实现 | 一路往下走，**不用回溯** | 后序：左右子树各返回候选，两侧都有 ⟹ 当前就是 LCA |
| 复杂度 | O(h) | O(n) |

## 复杂度提醒
BST 的所有操作都是 **O(h)**。
- 平衡时 h = O(log n)
- **退化成链时 h = O(n)**（按升序插入就会这样）

**不能无条件说 O(log n)** —— 这是 BST 和数组二分最大的区别：
数组二分**保证** O(log n)，BST 只有平衡时才有保证。
真实场景要用 AVL / 红黑树（本专题不涉及）。

## 常见错误
- LC-0098 只检查直接孩子，或者用 `<=` 允许相等。
- LC-0098 用 `int` 的极值当初始边界（节点值可能就是 `2^31-1`）—— 用 `±inf` 更安全。
- LC-0450 删除有两个孩子的节点时，只是把孩子接上去而不找替身。
- LC-0173 把整棵树先中序进数组（功能对，但违背题目的 O(h) 空间要求）。
- 把 BST 操作的复杂度说成「一定是 O(log n)」。
