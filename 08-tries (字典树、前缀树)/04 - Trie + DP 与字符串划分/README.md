# Level 1 · 04 Trie + DP 与字符串划分

## 核心定义
**Trie 是「加速匹配」的结构，DP 是「优化决策」的结构。** 两者职责完全不同，
组合起来解决「把字符串切成若干合法片段，使片段数最少」这类问题。

## LC-3291 Minimum Number of Valid Strings to Form Target I（P2）

### 题意澄清
Valid String = **words 中任意单词的非空前缀**（注意不是完整单词）。
目标：用最少个 Valid String 首尾拼接出 target。

### 两个结构各自负责什么

| | 负责 |
|---|---|
| **Trie** | 从 target 的位置 i 出发，**哪些长度的片段是合法的** |
| **DP** | 在这些合法片段里，**怎么选才能让总段数最少** |

### DP 状态
```
dp[i] = 拼出 target 前 i 个字符所需的最少段数
dp[0] = 0
dp[j] = min(dp[j], dp[i] + 1)   对每个从 i 出发、到 j 结束的合法片段
答案 = dp[n]，若为 INF 则返回 -1
```

**为什么状态是「前 i 个字符」**：拼接是从左到右、不重叠、无间隙的，
所以「已经拼好的部分」总是 target 的一个前缀，用一个下标就能完整描述。

### 用 Trie 找合法片段
把 words 全部插进 Trie。从位置 i 出发，沿 Trie 走 `target[i], target[i+1], ...`：
- 每走一步成功，`target[i..j]` 就是某个单词的前缀 ⟹ **它是一个 Valid String**
  ⟹ 立刻更新 `dp[j+1]`。
- **一旦走不动就 break** —— 再往后不可能有更长的合法片段了。这是关键的提前终止。

注意：因为任意**非空前缀**都算合法，所以**不需要检查 `is_end`** ——
只要路径走得通就行。这和 LC-0648（必须 `is_end`）正好相反，容易搞混。

### 复杂度
最坏 **O(n × L)**，n = len(target)，L = 最长单词长度
（每个起点最多沿 Trie 走 L 步）。空间 O(Σ|word| + n)。

**不要在没有证明的情况下说它是线性时间。**
如果需要真正的 O(n + Σ|word|)，要上 Z-function / 二分 + 哈希等更重的工具，
那超出本题范围。

### 边界
- target 无法拼出 → 返回 **-1**（dp[n] 仍是 INF）
- target 是空串 → 0
- 某个 word 本身就是 target
- words 里有重复

## 为什么标 P2
Trie + DP 的组合在面试里出现频率不高，
而且它的两个组成部分（Trie 匹配、线性 DP）在别处都已经单独练过。
本题的价值是**看清两种结构如何分工**，不是背代码。
