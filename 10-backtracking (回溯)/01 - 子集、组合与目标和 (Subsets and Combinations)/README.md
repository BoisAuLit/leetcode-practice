# Level 1 · 01 子集、组合与目标和 (Subsets and Combinations)

## 核心定义
从一个集合里**选一部分**（不关心顺序）。用 `start` 参数保证「不走回头路」，
从而每个组合只被枚举一次。

## 决定性观察
1. **`start` 是组合类题的灵魂**：
   - `dfs(i + 1)` ⟹ 每个元素**最多用一次**（子集、LC-0040、LC-0077）
   - `dfs(i)` ⟹ 同一个元素**可以重复用**（LC-0039）
   - 没有 `start`、改用 `used[]` ⟹ 那是**排列**（见 Level 1 `02`）
2. **子集 vs 组合的唯一区别是「什么时候记答案」**：
   - 子集：**每个节点**都是答案（`res.append(path[:])` 放在函数开头）
   - 固定大小的组合：**只有 `len(path) == k`** 时才记
   - 目标和：**只有 `remain == 0`** 时才记
3. **记答案必须拷贝**：`path[:]`，否则存的是同一个列表的引用。

## 去重：两种方式，看能不能排序

### 方式一：排序 + 相邻跳过（LC-0090 / LC-0040）
```python
nums.sort()
for i in range(start, n):
    if i > start and nums[i] == nums[i-1]:
        continue              # 同一层里，相同的值只取第一个
```
**`i > start` 而不是 `i > 0`** 是关键：
`i == start` 表示「这一层的第一个选择」，必须保留；
`i > start` 才是「同一层的后续重复值」，跳过。

**路径上的重复是允许的**：`[1,1]` 是 `[1,1,2]` 的合法子集。
我们去的是**同层**的重复分支，不是路径上的重复元素。

### 方式二：每层 set（LC-0491）
```python
used = set()                  # 只在本层有效
for i in range(start, n):
    if nums[i] in used: continue
    used.add(nums[i])
```
**用在不能排序的场合** —— LC-0491 求的是**子序列**，排序会破坏原始顺序。

## 题目

| # | 题 | 优先级 | 关键点 |
|---|---|---|---|
| 01/01 | LC-0078 Subsets | **P0** | 每个节点都记答案；`dfs(i+1)` |
| 01/02 | LC-0090 Subsets II | **P0** | 排序 + `i > start` 跳过重复 |
| 01/03 | LC-0491 Non-decreasing Subsequences | P2 | **不能排序** ⟹ 每层 set |
| 02/01 | LC-0077 Combinations | P1 | 固定大小 k；可加「剩余不够就剪枝」 |
| 03/01 | LC-0039 Combination Sum | **P0** | 元素**可重复用** ⟹ `dfs(i)` 而不是 `dfs(i+1)` |
| 03/02 | LC-0040 Combination Sum II | **P0** | 每个元素用一次 + 有重复值 ⟹ 排序去重 |
| 03/03 | LC-0216 Combination Sum III | P1 | 固定大小 k + 固定候选 1–9，两个约束叠加 |

## LC-0039 vs LC-0040（最容易混的一对）

| | LC-0039 | LC-0040 |
|---|---|---|
| 数组 | 元素**互不相同** | **可能有重复** |
| 每个元素 | 可以用**无限次** | 只能用**一次** |
| 递归 | `dfs(i, ...)` | `dfs(i + 1, ...)` |
| 去重 | **不需要**（元素本来就不重复） | **需要**排序 + 相邻跳过 |

两题都可以加一条强力剪枝：**排序后 `if nums[i] > remain: break`** ——
既然升序，后面的只会更大，整个分支直接砍掉。

## LC-0077 的剪枝
还需要 `k - len(path)` 个元素，但 `i` 后面只剩 `n - i` 个：
```python
for i in range(start, n - (k - len(path)) + 1):
```
这条上界剪枝能砍掉大量必然失败的分支。

## 复杂度
| 题 | 时间 |
|---|---|
| 子集 | O(2^n · n)（n 是拷贝路径的代价） |
| 组合 C(n,k) | O(C(n,k) · k) |
| 目标和 | 最坏指数级，取决于 target 和元素大小 |

**这类题的下界就是答案规模** —— 要输出 2^n 个子集，不可能比 O(2^n) 快。

## 常见错误
- `res.append(path)` 忘了拷贝 ⟹ 最后全是空列表。
- 去重写成 `i > 0` 而不是 `i > start` ⟹ 把路径上的合法重复也去掉了。
- LC-0040 忘了排序就用相邻跳过（相同的值不相邻，去重失效）。
- LC-0039 用了 `dfs(i+1)` ⟹ 元素不能重复用，答案缺失。
- 忘记 `path.pop()`。
