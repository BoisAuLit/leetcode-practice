# Level 1 · 04 网格搜索与约束满足 (Constraint Search)

本章是回溯最"重"的一章：搜索空间大，**全靠剪枝才能跑得动**。

## 01 - 网格路径与访问状态

### 通用骨架
```python
def dfs(r, c, ...):
    if 越界 or 不合法 or 已访问: return ...
    saved = grid[r][c]
    grid[r][c] = 标记            # 原地标记，比 visited 集合省内存
    for dr, dc in ((1,0),(-1,0),(0,1),(0,-1)):
        dfs(r + dr, c + dc, ...)
    grid[r][c] = saved           # ★ 必须恢复
```

### LC-0079 Word Search vs LC-0980 Unique Paths III

| | LC-0079 | LC-0980 |
|---|---|---|
| 要什么 | **存在**一条路径 | **数**所有路径 |
| 能否提前返回 | **能**（找到就 return True） | **不能**（必须走完整棵树） |
| 约束 | 字符匹配单词 | **必须覆盖所有空格** |
| 终止 | 匹配完整个单词 | 到终点**且** `remaining == 0` |

**「存在性」和「计数」的代码差异很大**：前者可以层层 `return True` 短路，
后者必须把所有分支的结果加起来。这是本节最该注意的一点。

LC-0980 的 `remaining` 计数要用样例校准 —— 不同写法的偏移量不同，
最容易差一。本仓库的实现是「进入起点时 `remaining = 空格数 + 1`，
到终点时判 `remaining == 0`」。

## 02 - N-Queens 与棋盘冲突检查

### 冲突检查的 O(1) 技巧（本节核心）
不要每次扫描整个棋盘。用三个集合：
```python
cols        # 用过的列
diag1       # r - c 相同 ⟹ 同一条「↘」对角线
diag2       # r + c 相同 ⟹ 同一条「↙」对角线
```
**为什么 `r - c` 和 `r + c` 能唯一标识对角线**：
沿 ↘ 走时 r 和 c 同增，`r - c` 不变；沿 ↙ 走时 r 增 c 减，`r + c` 不变。
（`r - c` 可能是负数，用 set 存没问题；用数组就加个偏移量 `r - c + n`。）

**逐行放置**天然保证了「每行一个皇后」，不需要额外检查行冲突。

### LC-0051 vs LC-0052
**完全同一个搜索**，区别只在终点：
- 051 要**所有棋盘布局** ⟹ 记录并拼出字符串，O(n! · n²)
- 052 只要**数量** ⟹ `count += 1`，省掉构造字符串的开销

（052 还能用位运算把三个 set 压成三个整数，是经典优化，但不必背。）

## 03 - 等和分桶与对称性剪枝（LC-0698）

**不剪枝必 TLE，剪枝后很快。四条缺一不可：**

1. **降序排序** —— 大的先放，最容易失败，**让失败尽早发生**（fail-fast）。
2. **跳过相同容量的桶**：`if buckets[j] == buckets[j-1]: continue`
   两个桶当前和相同时，放进哪个的后续搜索**完全同构** ——
   第一个失败，第二个必然也失败。**这条消除了桶之间的对称性，是关键中的关键。**
3. **放不下就跳过**：`if buckets[j] + x > target: continue`
4. **空桶等价**：放进空桶失败后 `break`，后面所有空桶都等价，不用再试。

**先做 O(n) 的可行性检查**：`sum % k != 0` 或 `max(nums) > target` ⟹ 直接无解。

**为什么 `i == n` 就一定成功**：总和是 `k * target`，每桶都 ≤ target，
所有数放完 ⟹ 每桶恰好 target，不需要再验证。

复杂度最坏 O(k^n)。**这个问题是 NP-complete，不要声称多项式时间。**

> LC-0473 Matchsticks to Square **就是 k=4 的本题**，所以没有单独收录。

## 04 - Sudoku 与多约束回溯（LC-0037）

三组约束同时成立：**行、列、3×3 宫**。
用三个数组做 O(1) 检查：
```python
rows[9][10], cols[9][10], boxes[9][10]      # boxes 下标 = (r // 3) * 3 + c // 3
```
**`(r//3)*3 + c//3` 是宫编号的标准算法**，要记住。

**进阶剪枝（MRV，Minimum Remaining Values）**：
优先填「候选数字最少」的格子，而不是按顺序填。
这是约束满足问题（CSP）的通用启发式，能把 Sudoku 从几秒降到毫秒级。
标 P2，**不要求背诵**，但知道这个名字有好处。

## 常见错误
- 忘记恢复原地标记 ⟹ 后续分支看到污染的网格。
- LC-0079 用 `visited` 但忘了从集合里 `remove`。
- LC-0980 把「存在性」的提前 return 照搬过来 ⟹ 只数到 1 条。
- N-Queens 用 `r + c` 和 `r - c` 时搞混哪个是哪条对角线（其实只要前后一致即可）。
- LC-0698 少写任何一条剪枝 ⟹ TLE。
- LC-0037 宫编号写成 `r // 3 + c // 3`（漏了 `* 3`）。

## 复习时的 Pattern Recognition
> 「在网格里找路径」 → 原地标记 + 四方向 + 回溯恢复。先问：**要存在性还是计数？**
> 「放置互不冲突的东西」 → 用集合做 O(1) 冲突检查。
> 「分成若干等和的组」 → 分桶回溯，**四条剪枝一条都不能少**。
