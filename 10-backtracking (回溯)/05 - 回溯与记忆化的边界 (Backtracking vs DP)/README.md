# Level 1 · 05 回溯与记忆化的边界 (Backtracking vs DP)

> 这个 Level 1 只有一道题，但它回答的是本专题最重要的一个问题：
> ## **什么时候**该用回溯，什么时候该**停止**用回溯？

## 判据（一句话）

> **要列出所有方案 ⟹ 只能回溯**（答案规模本身就是指数级，没有更快的可能）。
> **只要数量 / 最优值 / 能否达成 ⟹ 先找「状态」，能合并分支就上记忆化或 DP。**

**为什么能合并**：如果两条不同的搜索路径走到了**同一个状态**，
而且后续结果只取决于这个状态（和路径无关），那它们的子问题就是同一个 ——
算一次就够了。回溯之所以慢，就是因为它把同一个子问题反复算了很多遍。

## 对照表

| 题 | 要什么 | 该用什么 | 为什么 |
|---|---|---|---|
| LC-0078 Subsets | 所有子集 | **回溯** | 答案就有 2^n 个，无法更快 |
| LC-0046 Permutations | 所有排列 | **回溯** | 答案 n! 个 |
| LC-0051 N-Queens | 所有布局 | **回溯** | 要输出每一个棋盘 |
| **LC-0494** Target Sum | 方案**数** | **DP** | 状态 `(i, cur)` 可合并 |
| LC-0139 Word Break | 能否拆分（bool） | **DP** | 状态 `i` 可合并 |
| LC-0416 Partition Equal Subset | 能否划分（bool） | **DP** | 子集和背包 |
| LC-0140 Word Break II | 所有拆分**方案** | 回溯 + 记忆化 | 要方案，但子问题可缓存 |

**注意 LC-0139 和 LC-0140 的区别**：前者只要 bool ⟹ 纯 DP；
后者要所有方案 ⟹ 必须回溯，但可以缓存「从位置 i 开始的所有拆分」。

## LC-0494 Target Sum —— 三级演进（本章唯一的题）

### ① 朴素回溯 O(2^n)
```python
def dfs(i, cur):
    if i == n: return 1 if cur == target else 0
    return dfs(i+1, cur + nums[i]) + dfs(i+1, cur - nums[i])
```

### ② 记忆化 O(n · S)
**关键观察**：走到第 i 个数字时，**前面怎么选过无所谓**，
只要当前累计和 `cur` 相同，后面的结果就完全一样。
⟹ 状态是 `(i, cur)`，可以缓存。

**找到这个状态，是整道题唯一的思考步骤。** 剩下的都是机械变换。

### ③ 转成子集和 01 背包 O(n · sum)
设选 `+` 的数之和为 P，选 `-` 的为 N：
```
P + N = sum
P - N = target      ⟹  P = (sum + target) / 2
```
问题变成「**有多少个子集的和等于 P**」⟹ 经典 0-1 背包计数。

**两个无解判定（必须先做）**：
- `(sum + target)` 是**奇数** ⟹ 无解（P 必须是整数）
- `abs(target) > sum` ⟹ 无解

```python
dp = [0] * (P + 1); dp[0] = 1
for x in nums:
    for j in range(P, x - 1, -1):     # ★ 倒序 ⟹ 0-1 背包（每个数只用一次）
        dp[j] += dp[j - x]
```
**倒序是 0-1 背包的标志**；正序就变成完全背包（每个数可用多次），答案会错。

**含 0 的经典用例**：`[0,0,0,0,0,0,0,0,1]`, target=1 → **512**
（8 个 0 各有 `+`/`-` 两种选法）。上面的 DP 自动处理：`dp[j] += dp[j-0]` 让计数翻倍。

## 复杂度对照

| 解法 | 时间 | 空间 | 什么时候用 |
|---|---|---|---|
| 回溯 | O(2^n) | O(n) | n 很小；或需要列出方案 |
| 记忆化 | O(n · S) | O(n · S) | 从回溯平滑过渡，改动最小 |
| 01 背包 | **O(n · sum)** | O(sum) | 最优；需要先想出数学转化 |

## 面试里怎么答
1. 先说朴素回溯，**说出复杂度 O(2^n)**。
2. 指出「状态 `(i, cur)` 可以合并」⟹ 加记忆化。
3. 如果看得出数学转化，再给 01 背包版本。

**这个「从暴力到最优的推进过程」本身就是加分项**，
比直接甩出背包代码更能说明你理解了问题。
