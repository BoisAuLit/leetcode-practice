# 最终我建议你的脑内结构

不要把图论记成：

```text
DFS
BFS
Dijkstra
Bellman-Ford
Kahn
Union-Find
Prim
Kruskal
Hierholzer
```

这是一本算法教材的目录，但不一定是最好的**解题目录**。

你应该记成：

```text
图论题到底在问什么？

├── 能不能到？
│   └── DFS / BFS
│
├── 有几块？
│   └── DFS / BFS / Union-Find
│
├── 有没有环？
│   ├── undirected → DFS / Union-Find
│   └── directed → DFS states / Kahn
│
├── 有 dependency，求顺序？
│   └── Topological Sort
│
├── 最短路？
│   ├── unweighted → BFS
│   ├── non-negative → Dijkstra
│   └── negative → Bellman-Ford
│
├── 最便宜地把所有点连接？
│   └── MST → Prim / Kruskal
│
├── 每条边恰好走一次？
│   └── Eulerian → Hierholzer
│
├── 返回所有路径？
│   └── DFS + Backtracking
│
└── 动态判断 connectivity？
    └── Union-Find
```

**这个才应该成为你的主记忆树。**

你现在的目录不需要推翻重来，主要是把一级分类从「算法名」逐渐改成「问题类型」，再保留一个 `Algorithm Index` 做反向索引。这样既不会丢掉你现在已经积累的材料，又会让以后每道新题都有一个非常自然的位置。
