## 阶段 0:建图 · 隐式图 · 状态图

目标:看到任何输入都能说出"点是什么、边是什么",不用真的建图也能遍历。出关标准:能把 752 的"密码状态"和 127 的"单词"解释成图上的点。

- **997 Find the Town Judge** (E) ○ — 谁被所有人信任且不信任任何人;入度 n−1、出度 0。热身,练"度"的概念。
- **1971 Find if Path Exists in Graph** (E) ★ — 边列表建邻接表,u 能否到 v;建图 + DFS/BFS 的最裸模板。
- **841 Keys and Rooms** (M) ○ — 从 0 号房间出发能否进所有房间;有向图可达性,和 1971 一样只是方向性。
- **797 All Paths From Source to Target** (M) ○ — 枚举 DAG 上从 0 到 n−1 的所有路径;DFS + 回溯,path 进出。
- **133 Clone Graph** (M) ★ — 深拷贝一张图;遍历 + 哈希表"旧点 → 新点",面试高频。
- **1466 Reorder Routes to Make All Paths Lead to the City Zero** (M) ○ — 树上有向边,最少反转几条让所有城市能到 0;建图时给边打"正向/反向"标记,从 0 出发 DFS 数反向边。
- **752 Open the Lock** (M) ★ — 四位转盘锁最少转几次到目标,有死锁状态;**状态图 BFS** 签名题:点 = 一个四位串,边 = 拨一位。
- **127 Word Ladder** (H) ○ — 单词每次改一个字母,最少几步变成目标;隐式图 BFS,用通配符 `h*t` 建邻居;可升级成双向 BFS。
- **433 Minimum Genetic Mutation** (M) ○ — 127 的小号版,基因串每次改一个字符。
- **773 Sliding Puzzle** (H) △ — 2×3 滑块拼图最少几步复原;状态 = 整个棋盘序列化成字符串,BFS。
- **909 Snakes and Ladders** (M) △ — 蛇梯棋最少掷几次;一维编号和二维坐标互转,BFS。

## 阶段 1:DFS / BFS(静态、无权的连通性与步数)

目标:洪水填充、多源 BFS、边界反向 DFS 三个套路写到不用想。出关标准:200、994、417 三题各 10 分钟内盲写。

- **1254 Number of Closed Islands** (M) ○ — 不碰边界的岛有几个;先把边界相连的淹掉再数,"边界优先"套路。
- **1020 Number of Enclaves** (M) ○ — 走不出边界的陆地格有几个;同 1254,数格子而不是数岛。

- **417 Pacific Atlantic Water Flow** (M) ★ — 哪些格子的水既能流到太平洋又能流到大西洋;**边界反向 DFS** 签名题:从两边海岸往高处爬,取交集。
- **994 Rotting Oranges** (M) ★ — 腐烂传播到全部需要几分钟;**多源 BFS** 签名题:所有烂橘子一起进队列。
- **542 01 Matrix** (M) ○ — 每个格子到最近 0 的距离;多源 BFS,所有 0 一起出发。
- **286 Walls and Gates** (M,会员) ○ — 每个空房间到最近门的距离;同 542。
- **1162 As Far from Land as Possible** (M) ○ — 离陆地最远的海洋格有多远;多源 BFS 的最后一层。
- **1091 Shortest Path in Binary Matrix** (M) ○ — 八方向网格最短路;BFS 按层计数,练"层数 = 步数"。
- **1926 Nearest Exit from Entrance in Maze** (M) ○ — 从入口到最近出口几步;BFS,注意入口本身不算出口。
- **1197 Minimum Knight Moves** (M,会员) △ — 无限棋盘马走到目标最少几步;BFS + 对称剪枝。
- **547 Number of Provinces** (M) ○ — 邻接矩阵表示的朋友圈有几个;DFS 数连通块(也可并查集),和 200 的区别只是图的存法。
- **399 Evaluate Division** (M) ○ — 给 a/b = 2、b/c = 3,问 a/c;带权有向图上 DFS 累乘路径权重,"图可以有权但不需要最短路"的例子。
- **1376 Time Needed to Inform All Employees** (M) ○ — 消息从 CEO 传到所有人要多久;树上 DFS 求带权深度最大值。
- **2101 Detonate the Maximum Bombs** (M) △ — 引爆一个炸弹最多连锁多少个;先按距离建有向图,再从每个点 DFS 取最大。
- **2359 Find Closest Node to Given Two Nodes** (M) △ / **2360 Longest Cycle in a Graph** (H) △ — 每个点只有一条出边的"函数图";沿着唯一出边走并记录时间戳,是一类特殊的 DFS。

## 阶段 2:Union-Find(动态加边的连通性)

目标:并查集模板闭眼写;分清"静态用 DFS、动态用并查集"。出关标准:323、684、305 盲写,并能解释 `union` 返回值的用途。

- **323 Number of Connected Components in an Undirected Graph** (M,会员) ★ — 边列表数连通块;**并查集计数**签名题:块数 = n − 成功合并次数。
- **261 Graph Valid Tree** (M,会员) ○ — 边列表是不是一棵树;恰好 n−1 条边 + 没有一次 union 失败。
- **684 Redundant Connection** (M) ★ — 树多了一条边,找出来;**union 返回 False 即成环**签名题。
- **1319 Number of Operations to Make Network Connected** (M) ○ — 最少拔插几根网线连通所有电脑;线够不够 n−1 + 块数 − 1。
- **305 Number of Islands II** (H,会员) ★ — 格子逐个变陆地,每次报岛数;**动态加点 + count ± 1** 签名题。
- **721 Accounts Merge** (M) ○ — 有相同邮箱的账户合并;邮箱当点,并查集分组后按组输出,面试高频。
- **990 Satisfiability of Equality Equations** (M) ○ — 一堆 a==b、c!=d 能否同时成立;先 union 所有 ==,再逐个检查 != 是否同派。
- **1061 Lexicographically Smallest Equivalent String** (M,可能会员) ○ — 字符等价关系下每个位置的最小字符;并查集 + 每派记最小代表。
- **947 Most Stones Removed with Same Row or Column** (M) ○ — 同行或同列的石头可以互相消,最多消几个;答案 = 石头数 − 块数,行号和列号当点的建模技巧。
- **1202 Smallest String With Swaps** (M) ○ — 给定可交换的下标对,字典序最小的串;并查集分组,每组内排序回填。
- **1101 The Earliest Moment When Everyone Become Friends** (M,会员) ○ — 按时间顺序交朋友,何时全部连通;按时间排序 + union,剩一派时停——这就是 Kruskal 过程的雏形。
- **2316 Count Unreachable Pairs of Nodes in an Undirected Graph** (M) ○ — 互相不可达的点对数;各派 size 两两相乘,练 `size` 数组的用处。
- **952 Largest Component Size by Common Factor** (H) △ — 有公因数的数连边,最大连通块多大;把质因数当点来 union,建模题。
- **827 Making A Large Island** (H) △ — 最多翻一个 0,最大的岛多大;先给每块编号记 size,再枚举每个 0 把四周不同块加起来。
- **1559 Detect Cycles in 2D Grid** (M) △ — 同字符格子能否围成环;union 相邻同字符格子,失败即有环。
- **1627 Graph Connectivity With Threshold** (H) △ — 公因数大于阈值才连边,回答查询;枚举倍数来 union。
- **2092 Find All People With Secret** (H) △ — 会议按时间发生,秘密传给谁;同一时刻的会议一起 union,不知道秘密的人事后"重置",并查集的进阶用法。
- **685 Redundant Connection II** (H) △ — 684 的有向版;分"入度为 2"和"有环"两种情况讨论。

## 阶段 3:拓扑排序 · 有向图的环与依赖

目标:Kahn 和三色 DFS 都会,知道什么时候选哪个。出关标准:207、210 盲写;能说出"Kahn 顺带数了多少点,数不够就是有环"。

- **207 Course Schedule** (M) ★ — 课程有先修关系,能否全部修完;**Kahn** 签名题:入度为 0 的进队列,出队个数 < n 就有环。
- **210 Course Schedule II** (M) ○ — 输出一个可行的修课顺序;207 把出队顺序记下来。
- **802 Find Eventual Safe States** (M) ★ — 哪些点出发永远走不进环;**三色 DFS** 签名题(或把边反向后做 Kahn)。
- **1557 Minimum Number of Vertices to Reach All Nodes** (M) ○ — 最少从哪些点出发能到所有点;答案就是入度为 0 的点,练入度直觉。
- **310 Minimum Height Trees** (M) ○ — 以哪个点为根树最矮;从叶子一层层剥,最后剩的 1–2 个点——"剥叶子"就是无向图上的 Kahn。
- **269 Alien Dictionary** (H,会员) ○ — 从排好序的外星单词推出字母顺序;难点在相邻单词比较建边,再 Kahn,注意前缀特判。
- **1136 Parallel Courses** (M,会员) ○ — 每学期可修任意多门无依赖的课,最少几学期;Kahn 按层数轮数。
- **2115 Find All Possible Recipes from Given Supplies** (M) ○ — 有原料,哪些菜能做出来;配方当有向边,Kahn 从原料出发。
- **444 Sequence Reconstruction** (M,会员) △ — 给定子序列能否唯一确定原序列;Kahn 时队列里任何时刻都只有一个点。
- **1462 Course Schedule IV** (M) △ — 多组查询"a 是不是 b 的先修";拓扑序 + 每个点维护祖先集合,或 Floyd 传递闭包。
- **329 Longest Increasing Path in a Matrix** (H) ○ — 网格里最长递增路径;网格是 DAG,记忆化 DFS 就是 DAG 上的 DP。
- **2050 Parallel Courses III** (H) △ — 课程有时长,最少多少时间修完;拓扑序 + DP 求最长路。
- **1857 Largest Color Value in a Directed Graph** (H) △ — 有向图路径上同色点最多几个,有环返回 −1;Kahn 同时做 DP。
- **1203 Sort Items by Groups Respecting Dependencies** (H) △ — 两层依赖(组之间、组内);做两次拓扑排序。

## 阶段 4:最短路(带权)

目标:Dijkstra 堆版闭眼写,知道 relax 那一行怎么改;Bellman-Ford 快照版和 Floyd 能写。出关标准:743、787、1334 盲写;能解释为什么 Dijkstra 不能有负权。

- **743 Network Delay Time** (M) ★ — 信号从一个点传到所有点要多久;**Dijkstra 堆版**签名题,答案是 dist 的最大值。
- **1514 Path with Maximum Probability** (M) ○ — 成功概率最大的路径;relax 从 `d + w` 改成 `d * p`,堆改成大根堆(存负数)。
- **1631 Path With Minimum Effort** (M) ○ — 路径上相邻高度差的最大值最小;relax 改成 `max(d, w)`,瓶颈路径。
- **778 Swim in Rising Water** (H) ○ — 水位涨到多少能游到终点;同 1631,阈值在格子上;也可 Kruskal 过程 / 二分 + BFS,三种解法都要会说。
- **1102 Path With Maximum Minimum Value** (M,会员) ○ — 路径最小值最大;relax 改成 `min(d, w)` + 大根堆。
- **1976 Number of Ways to Arrive at Destination** (M) ○ — 最短路有几条;Dijkstra 加一个 `ways` 数组,相等时累加,严格更小时覆盖。
- **505 The Maze II** (M,会员) △ — 球滚到墙才停,最短滚动距离;Dijkstra,"邻居"是滚到底的位置。
- **1368 Minimum Cost to Make at Least One Valid Path in a Grid** (H) ○ — 每格有默认方向,改方向花 1,最少花多少到终点;**0-1 BFS**:顺着方向走代价 0 放队头,改方向代价 1 放队尾。
- **2290 Minimum Obstacle Removal to Reach Corner** (H) ○ — 最少拆几个障碍到终点;0-1 BFS,障碍格代价 1。
- **787 Cheapest Flights Within K Stops** (M) ★ — 最多转 k 次的最便宜航班;**Bellman-Ford 跑 k+1 轮、每轮用快照**签名题。Dijkstra 直接做会错,要能解释为什么。
- **1334 Find the City With the Smallest Number of Neighbors at a Threshold Distance** (M) ★ — 点数 ≤ 100,每个城市在阈值内能到几个城市;**Floyd** 签名题。
- **2976 Minimum Cost to Convert String I** (M) ○ — 字符转换有代价,整串最少花多少;26 个字母上跑 Floyd。
- **2642 Design Graph With Shortest Path Calculator** (H) △ — 支持加边和查询最短路;每次查询跑一遍 Dijkstra。
- **1928 Minimum Cost to Reach Destination in Time** (H) △ — 时间限制内最便宜的路;Dijkstra 的状态变成 (点, 已用时间)。
- **2577 Minimum Time to Visit a Cell In a Grid** (H) △ — 格子有最早可进入时间,可以来回踱步等待;Dijkstra + 奇偶性处理等待。
- **2812 Find the Safest Path in a Grid** (M) △ — 离小偷最远的一条路;先多源 BFS 算每格安全度,再做最大最小值路径。
- **2203 Minimum Weighted Subgraph With the Required Paths** (H) △ — 从两个源到一个终点的最小总权;正图跑两次 Dijkstra、反图跑一次,枚举汇合点。

## 刷题路线

**核心线(39 题,顺序即优先级)**。全部是 ★ 和最重要的 ○,做完就覆盖了 FAANG 图论的考点:

1. 阶段 0:1971 → 133 → 752 → 127 → 797 → 1466
2. 阶段 1:200 → 695 → 994 → 542 → 417 → 130 → 1254 → 547 → 1091
3. 阶段 2:323 → 684 → 1319 → 305 → 721 → 990 → 947 → 1101
4. 阶段 3:207 → 210 → 802 → 310 → 269 → 1136 → 329
5. 阶段 4:743 → 1514 → 1631 → 1368 → 787 → 1334 → 1976
6. 阶段 5:1584(三种写法)→ 1489 → 1697 → 1970
7. 阶段 6:785 → 1192 → 332

**扩展线**:核心线做完后,按"你最弱的阶段"回头补该阶段的 ○,最后才碰 △。△ 里面优先级最高的三道是 827、2050、2577,因为它们分别代表"并查集 + 枚举"、"拓扑 + DP"、"Dijkstra + 状态"这三个高频组合。

**节奏**。按你之前定的每周 3–4 题的维护节奏,核心线约 10–12 周;如果近期有面试,把阶段 1–4 的签名题(200、994、417、323、684、207、802、743、787)提到最前面一周内过完,它们覆盖了八成的图论面试题。

**每道题的做法**。动手前先答那五个问题(点和边是什么、有没有权、图会不会变、有没有方向、问的是哪一类),说出它属于哪个阶段、用哪个签名题的模板;做完在文件头写一行"和签名题比改了哪一行"。改动写不出来,说明还没真正归类,回去重做。

**复习**。只有 ★ 签名题进 review_due 系统,按 1、3、7、14、30 天间隔盲写模板;○ 和 △ 不复习,靠"改一行"的记忆挂在签名题上。每个阶段结束做一次出关测试(上面每个阶段标题下那句),没过就不进下一阶段。

**检验标准**。核心线走完后,随便抽一道 ○ 题,你应该能在 2 分钟内说出阶段、模板和要改的那一行,再在 15 分钟内写完——做到这一点,图论对你来说就不再"繁杂",只是一张 7 行的表。
