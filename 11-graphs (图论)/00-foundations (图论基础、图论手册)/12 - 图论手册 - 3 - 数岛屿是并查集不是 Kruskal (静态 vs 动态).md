问得好,这里正好有一个容易混淆的边界,值得单独说清楚。

**数岛屿(LC 200)不是 Kruskal,它只是并查集。**

Kruskal = 排序 + 并查集 + 只要不成环的边。它的灵魂是"按价格排队"和"买最便宜的"。数岛屿里没有价格、不用排序、也不需要选边——它只问"这些格子分成几块"。能用并查集解,只是因为并查集是 Kruskal 用到的一个零件,但用了零件不等于用了整台机器。类比:Dijkstra 用了堆,不代表所有用堆的题都是 Dijkstra。

所以 LC 200 不属于"Prim/Kruskal 能解决的其他问题"这五层中的任何一层。它属于我们手册第 4 章那个独立的家族:**连通性 / 连通块计数**,标准做法是 BFS/DFS 洪水填充,并查集是备选。

**但它的"动态版本"确实属于第三层。**

区别只在一个字:图是**静态**的还是**动态**的。

- 静态:整张图一开始就给全了,只问一次。用 DFS/BFS 最简单,O(mn),代码比并查集短。
- 动态:格子一块一块加进来,每加一块就要报一次岛数。DFS 每次重数一遍是 O(k·mn),太慢;并查集"每加一块就 union 一下、维护一个计数"是 O(k·α),这正是第三层"按时间逐个加入 + 并查集 + 随时读答案"的骨架——门槛就是时间步。

动态版本的核心只有两行:新加一块地,先当它是一座新岛 `count += 1`;然后和四周已有的陆地 union,**每成功合并一次就 `count -= 1`**(两座岛接成一座)。

```python
def numIslands2(m, n, positions):                   # LC 305 Number of Islands II
    uf = UnionFind(m * n)                           # 格子 (r, c) 编号 r * n + c
    land = [[False] * n for _ in range(m)]
    count = 0
    ans = []
    for r, c in positions:
        if land[r][c]:                              # 重复加同一格:岛数不变
            ans.append(count)
            continue
        land[r][c] = True
        count += 1                                  # 先当它是一座新岛
        for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            nr, nc = r + dr, c + dc
            if 0 <= nr < m and 0 <= nc < n and land[nr][nc]:
                if uf.union(r * n + c, nr * n + nc):
                    count -= 1                      # 和一座已有的岛接上了,少一座
        ans.append(count)
    return ans
```

已经和暴力数岛法在 500 组随机输入上交叉验证过。

**岛屿家族的题分别落在哪**

| 题 | 题目在问 | 归属 | 首选做法 |
|---|---|---|---|
| **LC 200 Number of Islands** | 静态网格,1 是陆地,数有几座岛 | 连通块计数(手册第 4 章),不是 Kruskal | DFS/BFS 洪水填充;并查集也行但更长 |
| **LC 695 Max Area of Island** | 静态网格,最大的岛有几格 | 同上 | DFS 顺便数格子;并查集用 `size` 也行 |
| **LC 305 Number of Islands II** | 格子逐个变陆地,每次加完报岛数 | **第三层**:按时间逐个加入 + 并查集 | 上面的代码,`count ± 1` |
| **LC 1970 Last Day Where You Can Still Cross** | 格子逐个变水,问最后哪天还能上下穿越 | **第三层**:时间倒放后变成逐个加入 | 上一条笔记里讲过 |
| **LC 827 Making a Large Island** | 静态网格,最多把一个 0 改成 1,最大的岛能有多大 | 连通块 + 查询,不是 Kruskal | 并查集(或 DFS 染色)先算每块的大小,再枚举每个 0,把四周不同块的大小加起来 |
| **LC 130 Surrounded Regions** | 把没碰到边界的 O 区域全改成 X | 连通块,不是 Kruskal | 从边界 O 开始 DFS 标记(你做过的做法);并查集要加一个虚拟"边界点" |

**记一条判断规则**

看到"数块数 / 分组 / 连不连通"的题,先问:**图会不会变?** 不变 → DFS/BFS;一条条加 → 并查集,这才是第三层。再问:**边有没有价格、要不要挑便宜的?** 有 → Kruskal;没有 → 只是并查集。四种组合里只有"会变 + 有价格"才是完整的 Kruskal(比如 1697),"会变 + 没价格"是并查集增量计数(305),"不变 + 有价格"是建完树看结构(1489),"不变 + 没价格"就是普通连通块(200)。
