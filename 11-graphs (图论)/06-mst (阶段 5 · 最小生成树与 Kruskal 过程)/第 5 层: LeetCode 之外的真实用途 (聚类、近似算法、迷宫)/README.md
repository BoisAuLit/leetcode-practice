# 第 5 层: LeetCode 之外的真实用途 (聚类、近似算法、迷宫)

**这一层没有 LeetCode 题，不进复习队列。** 它的用处是：面试聊到项目、或者以后做 AI / RAG 的时候，知道 MST 不只是一道算法题。

可运行的 demo：[kruskal_applications.py](kruskal_applications.py)（`python3 kruskal_applications.py`），三个用途共用一个 Kruskal，区别只在"什么时候停"和"边权是什么"。

| 用途 | 怎么用 Kruskal | 代码里的函数 |
|---|---|---|
| 单链接层次聚类 | 跑到**剩 k 派就停**，这 k 派就是 k 个簇 | `single_linkage(points, k)` |
| TSP 的 2 倍近似 | 先建完 MST，再沿树做一遍**先序遍历** | `tsp_two_approx(points)` |
| 随机迷宫生成 | 给每道墙一个**随机权重**跑 Kruskal | `random_maze(rows, cols)` |
| 图像分割 (Felzenszwalb) | 像素是点，相邻像素颜色差是边权，合并时加一个"差异够不够小"的判断 | 概念，没写代码 |
| 网络设计 | 布电缆、铺管道、电路板走线，MST 的原产地 | 概念 |

## 单链接聚类（和你往 AI 方向走最相关的一个）

对 n 个点跑 Kruskal，**在剩 k 个集合时停下**，等价于建完 MST 后砍掉最贵的 k−1 条边。它保证的是"不同簇之间的最小距离尽量大"，因为砍掉的恰好是最长的那些连接。

做 embedding 去重、文档聚类时这是基础方法之一：点换成向量，距离换成余弦距离，其他一个字不改。

demo 里已经把这个等价关系跑出来了：`single_linkage(pts, 3)` 和"砍掉 MST 最贵的 2 条边"给出同一个分组。400 组随机点验证过两者完全一致。

## TSP 的 2 倍近似

TSP 要最短的、经过所有点一次的回路，没有快速精确解。但 MST 给得出一个保证不超过最优 2 倍的答案，三步推理：

1. MST 总长 ≤ 最优回路（回路去掉一条边就是一棵生成树，而 MST 是最便宜的生成树）。
2. 沿 MST 每条边走两次，得到一条闭合散步，长度 = 2 × MST ≤ 2 × 最优。
3. 把重复经过的点跳过（= 先序遍历），距离满足三角不等式时跳过不会更长。

300 组随机点验证过：每一组都 ≤ 2 倍最优，实测最差比值 1.31。

## 随机迷宫

格子是点，相邻格之间的"墙"是边，权重随机。Kruskal 留下的 n−1 条边就是要打通的墙：生成树没有环（迷宫无回路）且连通（任意两格都走得到）。300 组随机尺寸验证过，每次都恰好 n−1 条边且连通。

## 做不到的事，一起记住

- **有向图**：有向图上"从根出发能到所有点、总价最小"的树叫最小树形图，Prim 和 Kruskal 都不适用，要用朱-刘 / Edmonds 算法。
- **MST 上的路不是最短路**：三角形 A–B 1、B–C 1、A–C 1.5，MST 是 {A–B, B–C}，树上 A 到 C 要走 2，但直接走 A–C 只要 1.5。想要距离最短用 Dijkstra；MST 上的路径保证的是瓶颈最小，不是总和最小。
- **限制度数的生成树、Steiner tree**（只需连通指定的几个点，可以借用其他点）：都是 NP-hard，MST 只能给近似解。
