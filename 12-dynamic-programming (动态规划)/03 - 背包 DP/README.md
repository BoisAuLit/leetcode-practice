# Level 1 · 03 背包 DP

## 本章唯一需要死记的东西

> ## **0-1 背包 → 容量倒序；完全背包 → 容量正序**

```python
# 0-1 背包（每个物品最多用一次）
for item in items:
    for j in range(capacity, item - 1, -1):      # ★ 倒序
        dp[j] = max(dp[j], dp[j - item] + value)

# 完全背包（每个物品可以用无限次）
for item in items:
    for j in range(item, capacity + 1):          # ★ 正序
        dp[j] = min(dp[j], dp[j - item] + 1)
```

**为什么倒序 = 只用一次**：计算 `dp[j]` 时读的是 `dp[j - item]`。
倒序时 `dp[j - item]` **还是上一轮（没放这个物品）的值** ⟹ 这个物品只被放了一次。
正序时 `dp[j - item]` **已经是本轮更新过的**（可能已经放过这个物品）⟹ 可以重复放。

**一句话**：倒序读「旧值」，正序读「新值」。

## 四个维度的变化

| 变化点 | 怎么改 | 例题 |
|---|---|---|
| 物品能用几次 | 倒序 / 正序 | 0-1 vs 完全 |
| 容量有几个维度 | dp 几维 + 几层倒序 | **LC-0474**（两维） |
| dp 的值是什么 | bool 可达 / max 价值 / **计数** | 0416 / 0322 / 0494、0518 |
| 组合还是排列 | **循环嵌套顺序**（见下） | LC-0518 vs LC-0377 |

## 组合 vs 排列（本章第二个必记点）

```python
# 组合数（{1,2} 和 {2,1} 算一种）—— 物品在外层
for coin in coins:
    for j in range(coin, amount + 1):
        dp[j] += dp[j - coin]

# 排列数（{1,2} 和 {2,1} 算两种）—— 容量在外层
for j in range(1, target + 1):
    for num in nums:
        if num <= j: dp[j] += dp[j - num]
```

> **物品在外层 ⟹ 组合；容量在外层 ⟹ 排列。**
> LC-0518 Coin Change II 求组合数，LC-0377 Combination Sum IV 求排列数 ——
> 两题的代码差别**只有两层循环的顺序**。这是本章最容易混的一点。

## 五个小节

| 小节 | dp 的值 | 遍历 | 题目 |
|---|---|---|---|
| 01 0-1 可达性 | **bool** | 倒序 | LC-0416、LC-1049 |
| 02 0-1 计数 | **方案数** | 倒序 | LC-0494 |
| 03 二维容量 | max / 计数 | **两层都倒序** | LC-0474、LC-0879 |
| 04 完全背包最少数量 | **最少个数** | 正序 | LC-0322 |
| 05 完全背包计数 | 方案数 | 正序，**注意嵌套顺序** | LC-0518（组合）、LC-0377（排列） |

## 各题的「转化」步骤（难点往往在这里，不在 DP）

| 题 | 转化 |
|---|---|
| **LC-0416** | 划分成两个和相等的子集 ⟺ **能否选出和为 `sum/2` 的子集**。`sum` 为奇数直接 False |
| **LC-1049** | 对撞 ⟺ 给每块石头赋 ±；答案 = `total − 2 × (不超过 total/2 的最大可达和)` |
| **LC-0494** | `P + N = sum`、`P − N = target` ⟹ `P = (sum+target)/2`，变成子集和计数。`(sum+target)` 为奇数或 `|target| > sum` ⟹ 0 |
| **LC-0474** | 「0 的个数」和「1 的个数」是**两个独立容量**，价值都是 1 |
| **LC-0879** | 利润「至少 minProfit」是**无界维度** ⟹ `min(minProfit, p + profit)` **封顶** |
| **LC-0322** | 完全背包求**最少个数**，`dp` 初值 `inf`，`dp[0] = 0`，最后 `inf` 要返回 -1 |

## 初始化的三种情形

| dp 的值 | `dp[0]` | 其余 |
|---|---|---|
| bool 可达 | `True`（空集和为 0） | `False` |
| 方案数 | `1`（空集算一种） | `0` |
| 最少个数 | `0` | `inf`（表示不可达） |

**`dp[0]` 设错是背包题最常见的 bug。**

## 复杂度
| 题 | 时间 | 空间 |
|---|---|---|
| 一维容量 | O(n · capacity) | O(capacity) |
| 二维容量 | O(n · m · k) | O(m · k) |

**注意这是「伪多项式」**：复杂度和**数值大小**（capacity）成正比，而不是输入长度。
LC-0416 的 `sum` 可达 20000，LC-0879 的 `minProfit ≤ 100` ——
题目给的数值上界就是在暗示能不能用背包。

## 常见错误
- 倒序 / 正序写反。
- 二维容量只倒序了一个维度。
- `dp[0]` 初始化错（计数题设成 0、可达性题设成 False）。
- LC-0518 和 LC-0377 的循环嵌套顺序写反。
- LC-0322 忘了把 `inf` 转成 -1。
- LC-0494 漏掉两个无解判定。

## 复习时的 Pattern Recognition
> 「能否凑出 / 最少用几个 / 有多少种凑法」+「容量有上界」
> → 背包。先问四件事：
> **① 物品能用几次？② 容量几个维度？③ dp 的值是什么？④ 组合还是排列？**
