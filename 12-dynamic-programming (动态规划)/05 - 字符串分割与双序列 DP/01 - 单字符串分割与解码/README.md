# Level 2 · 01 单字符串分割与解码

## 通用骨架
```python
dp[0] = 初始值
for i in range(1, n + 1):
    for j in range(i):                  # 枚举最后一段 s[j:i]
        if 合法(s[j:i]):
            dp[i] = 合并(dp[i], dp[j])
```
**枚举「最后一段从哪里开始」** —— `合法()` 换一下就是另一道题。

## 本 Level 2 的题目

| # | 题 | `dp[i]` 的含义 | 「合法」是什么 | 位置 |
|---|---|---|---|---|
| 01 | **LC-0091** Decode Ways | 前 i 个字符的解码方案数 | 一位（非 `'0'`）或两位（`10`–`26`） | 本目录 |
| 02 | **LC-0139** Word Break | 前 i 个字符能否拆分 | `s[j:i] in wordDict` | 本目录 |
| — | **LC-3291** Min Valid Strings | 前 i 个字符最少几段 | 是 words 中某单词的**非空前缀** | **跨专题索引**，见下 |

### 它的 DP 视角（本专题关心的部分）
```
dp[i] = 拼出 target 前 i 个字符所需的最少段数
dp[0] = 0；答案 dp[n]，若为 INF 返回 -1
从位置 i 出发沿 Trie 走，每走通一步就得到一个合法片段 ⟹ 更新 dp[j+1]
一旦走不通就 break（再往后不可能更长）
```

**Trie 负责「哪些片段合法」，DP 负责「怎么选最少」** —— 两个结构职责完全不同。

**一个容易混的点**：本题的合法片段是「某个单词的**非空前缀**」，
所以沿 Trie 走时**不需要检查 `is_end`**，路径走得通就算合法。
这和 LC-0648 Replace Words（必须 `is_end`）正好相反。

## LC-0091 的三个坑（这题的全部难度在边界）
1. `'0'` **不能**单独解码 ⟹ `s[i-1] != '0'` 才能取一位。
2. 两位必须在 `10`–`26` 之间 ⟹ `'06'` 不合法（前导零）。
3. `dp[0] = 1`（空串算一种解法）；`s[0] == '0'` 时直接返回 0。

## LC-0139 vs LC-0140
- **LC-0139** 只要 bool ⟹ 纯 DP，O(n²) 或用 Trie 加速。
- **LC-0140** 要**所有拆分方案** ⟹ 必须回溯（但子问题可缓存）。
  见 [10-backtracking](<../../../10-backtracking (回溯)/05 - 回溯与记忆化的边界 (Backtracking vs DP)/01 - 从回溯到记忆化再到 DP/README.md>)
  里「要列出所有方案 ⟹ 只能回溯」那条判据。
