# Level 1 · 06 网格路径与空间 DP

## 核心定义
`dp[i][j]` = 走到格子 `(i, j)` 时的答案。只能从**上面**或**左边**来
⟹ 转移固定，遍历顺序也固定（从上到下、从左到右）。

## 基本模板
```python
for i in range(m):
    for j in range(n):
        if i == 0 and j == 0: dp[i][j] = init
        else: dp[i][j] = 合并(dp[i-1][j] if i else 无效,
                              dp[i][j-1] if j else 无效) + grid[i][j]
```

**空间优化到 O(n)**：只依赖上一行和本行左边 ⟹ 滚动一行即可。
```python
for i in range(m):
    for j in range(n):
        dp[j] = min(dp[j],              # 上面（上一轮的 dp[j]）
                    dp[j-1]) + grid[i][j]   # 左边（本轮已更新的 dp[j-1]）
```
**这里正好利用了「`dp[j]` 还是旧值、`dp[j-1]` 已是新值」** —— 和背包的倒序正序是同一个道理。

## 三个小节

| 小节 | dp 的值 | 题目 |
|---|---|---|
| 01 路径计数 | 方案数 | LC-0062、LC-0063 |
| 02 最小代价 | 最小和 | LC-0064、LC-0931、LC-0120、**LC-0174** |
| 03 二维结构状态 | 以 (i,j) 为**右下角**的最大正方形边长 | LC-0221 |

## 各题要点

| 题 | 优先级 | 关键点 |
|---|---|---|
| **LC-0062** Unique Paths | **P0** | 纯计数；也有组合数公式 `C(m+n-2, m-1)` |
| **LC-0063** Unique Paths II | P1 | 有障碍 ⟹ `dp[i][j] = 0`。**第一行/列遇到障碍后全是 0** |
| **LC-0064** Minimum Path Sum | **P0** | 最基础的最小代价 |
| **LC-0931** Minimum Falling Path Sum | P1 | 可以走**左下/下/右下**三个方向 ⟹ 三个候选取 min |
| **LC-0120** Triangle | P1 | **自底向上消除边界特判**，见下 |
| **LC-0174** Dungeon Game | P2 | **必须从终点倒推**，见下 |
| **LC-0221** Maximal Square | P1 | `dp[i][j] = min(上, 左, 左上) + 1`，见下 |

## LC-0120：换方向就消掉了边界特判

**自顶向下**时每行的**首尾**都是特例（只有一个来源）⟹ 要写三个分支。
**自底向上**时 `dp[i] = min(dp[i], dp[i+1]) + row[i]` ——
**每个位置都有两个合法来源，没有任何特例**。

```python
dp = triangle[-1][:]
for row in reversed(triangle[:-1]):
    for i in range(len(row)):
        dp[i] = row[i] + min(dp[i], dp[i + 1])
return dp[0]
```
O(n) 空间，而且代码短一半。**「换个方向推，边界特判就消失」是很值钱的经验。**

## LC-0174：本章最重要的一道题 —— **必须倒推**

**为什么正推不行**：定义「从起点走到 (i,j) 的最优值」时，
「剩余血量最多」和「所需初始血量最少」**不等价** ——
剩血多的路径可能中途掉到 0 以下而非法。**局部最优不构成全局最优。**

**改成倒推**，状态自洽了：
```
dp[i][j] = 从 (i,j) 出发走到终点，【进入 (i,j) 之前】至少需要多少血
dp[i][j] = max(1, min(dp[i+1][j], dp[i][j+1]) - dungeon[i][j])
```
**`max(1, ...)`** 是关键：遇到大血包时算出来可能 ≤ 0，
但**进入任何格子之前至少得有 1 点血**。

> **当「从起点出发」的状态定义不出自洽的最优子结构时，试试从终点倒推。**
> 这是本专题经验③。

## LC-0221：状态定义是「以 (i,j) 为右下角」

```python
if matrix[i][j] == '1':
    dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1
```
**为什么取三个的 min**：要以 (i,j) 为右下角构成边长 k 的正方形，
它上方、左方、左上方都必须能构成边长 ≥ k-1 的正方形。**短板决定了 k。**

答案是 `max(dp)²`（面积），不是 `dp[m-1][n-1]`。

**和 LC-0085 Maximal Rectangle 的区别**：正方形有这个漂亮的 min 递推；
矩形没有，必须转成「每行一个柱状图 + 单调栈」（见 [18-monotonic](<../../18-monotonic-fuck-you (单调栈、单调队列)/README.md>)）。

## 复杂度
全部 **O(m·n)** 时间，**O(n)** 空间（滚动一行）。
LC-0062 用组合数公式可以 O(min(m,n)) 时间 O(1) 空间。

## 常见错误
- LC-0063 第一行/列遇到障碍后，后面没有全部置 0。
- LC-0120 用自顶向下却漏写首尾特例。
- LC-0174 试图正推。
- LC-0174 忘了 `max(1, ...)`。
- LC-0221 返回边长而不是面积，或者返回 `dp[m-1][n-1]` 而不是全局 max。
- 一维滚动时方向搞反（应该从左到右，让 `dp[j-1]` 是新值）。

## 复习时的 Pattern Recognition
> 「从左上走到右下，有多少种走法 / 最小代价」 → 基本网格 DP。
> 「路径上有任意时刻都必须满足的硬约束」 → **倒推**。
> 「最大全 1 正方形」 → `min(三个方向) + 1`。
