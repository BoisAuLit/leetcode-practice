# Level 1 · 07 股票与状态机 DP

> ## **这六道题是同一道题。**
> 一个状态机 + 不同的限制，**不要当成六道题去背**。

## 统一状态机（本章唯一需要记的东西）

```python
hold = 今天结束时「持有一股」的最大利润
free = 今天结束时「不持有」的最大利润

hold = max(hold, free - price)      # 继续持有 / 今天买入
free = max(free, hold + price)      # 继续空仓 / 今天卖出
初始：hold = -prices[0]，free = 0
答案：free
```

## 六道题的区别只在这张表

| 题 | 限制 | 怎么改 |
|---|---|---|
| **LC-0121** | 只能交易**一次** | 买入时用 `-price` 而不是 `free - price`（不能用卖出的钱再买） |
| **LC-0122** | **无限次** | 上面的裸状态机 |
| **LC-0309** | 卖出后**冷却 1 天** | 买入用 `free_prev_prev - price`（跳过一天） |
| **LC-0714** | 每笔**收手续费** | 卖出时 `hold + price - fee` |
| **LC-0123** | 最多 **2** 次 | 四个变量：`buy1 / sell1 / buy2 / sell2` |
| **LC-0188** | 最多 **k** 次 | 两个长度 k+1 的数组：`buy[t] / sell[t]` |

**看清这件事，股票系列就从六道题变成一个模板。**

## 三个小节

### 01 - 单次与无限次

**LC-0121（一次）**：等价于「最小价格 + 最大差值」，一行贪心也行：
```python
min_price = min(min_price, p); best = max(best, p - min_price)
```

**LC-0122（无限次）**：**贪心也对** —— 答案 = 所有相邻上涨差之和。
```python
sum(max(0, prices[i] - prices[i-1]) for i in range(1, n))
```
**为什么**：任何一段上涨 `a → b` 都能拆成逐日小段，拆开买卖的总利润
不小于一次性买卖（`(p2-p1)+(p3-p2) = p3-p1`）；下跌日贡献 0。

> ⚠️ **但贪心只在「无限次交易」时成立。**
> 加上次数限制、冷却、手续费之后**贪心全都不对**，必须回到状态机。
> **不要把一道题的贪心结论推广到整个系列。**

### 02 - 冷却期与交易费用

**LC-0309（冷却 1 天）**：卖出后第二天不能买 ⟹ 买入要用**两天前**的 `free`：
```python
hold = max(hold, free_prev_prev - price)
free_prev_prev = free_prev; free_prev = free
```
需要多存一个变量。

**LC-0714（手续费）**：只改一处 —— 卖出时扣掉 fee：
```python
free = max(free, hold + price - fee)
```
（在买入时扣也等价，但**不能两边都扣**。）

### 03 - 交易次数限制

**LC-0123（k=2）** 四个变量顺序更新：
```python
buy1  = max(buy1,  -p)
sell1 = max(sell1, buy1 + p)
buy2  = max(buy2,  sell1 - p)
sell2 = max(sell2, buy2 + p)
```
**为什么可以用本轮刚更新的值**：那相当于「同一天先买再卖」，利润 `-p + p = 0`，
不会凭空多出利润，也不会漏掉更优方案。面试被追问时这么解释。

**LC-0188（一般 k）**：
```python
for p in prices:
    for t in range(1, k + 1):
        buy[t]  = max(buy[t],  sell[t-1] - p)
        sell[t] = max(sell[t], buy[t] + p)
```

**LC-0188 的必要优化**：`k >= n // 2` 时限制失效（最多也只能做 n//2 笔）
⟹ **直接退化成 LC-0122 的贪心**。不做这个判断，k 很大时会 MLE / TLE。

## 复杂度

| 题 | 时间 | 空间 |
|---|---|---|
| LC-0121 / 0122 / 0309 / 0714 | O(n) | **O(1)** |
| LC-0123 | O(n) | **O(1)**（四个变量） |
| LC-0188 | O(n·k) | O(k) |

## 常见错误
- LC-0121 用了 `free - price`（允许了多次交易）。
- LC-0309 只跳了一个状态而不是两天前的 `free`。
- LC-0714 在买入和卖出**两边都扣**了手续费。
- LC-0188 忘了 `k >= n // 2` 的退化判断。
- 把 LC-0122 的贪心套到有限制的题上。
- 更新 `hold` / `free` 时没注意「用的是上一轮还是本轮的值」。

## 复习时的 Pattern Recognition
> 「买卖股票」「最多 k 次操作」「操作后有冷却」
> → 状态机 DP。先问：**有几个状态？有几个限制？限制怎么加进转移里？**
>
> 更一般地：**凡是「在若干离散状态之间转移、每个状态维护一个最优值」的题，都是状态机 DP。**
