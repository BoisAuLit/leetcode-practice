# Level 1 · 08 区间 DP 与博弈

## 核心定义
`dp[i][j]` = 区间 `[i, j]` 上的答案。
**遍历顺序必须保证小区间先算完** —— 这是区间 DP 唯一的硬性要求。

两种正确的写法：
```python
# ① 按区间长度从小到大
for length in range(2, n + 1):
    for i in range(n - length + 1):
        j = i + length - 1
        ...

# ② i 倒序 + j 正序（更简洁）
for i in range(n - 1, -1, -1):
    for j in range(i + 1, n):
        ...   # 用到的 dp[i+1][*] 和 dp[*][j-1] 都更短，已算完
```

## 两种转移思路

| 思路 | 看什么 | 例题 |
|---|---|---|
| **看两端** | `s[i]` 和 `s[j]` 是否相等 | LC-0516、LC-1312 |
| **枚举「最后一步」** | 区间内枚举 k 作为最后操作的位置 | **LC-0312**、**LC-1547** |

### 为什么是「最后一步」而不是「第一步」（本章最重要的一条）

枚举**最后一步** k 时，`[i, k]` 和 `[k, j]` 两段已经被 k 分开，
**互不影响** ⟹ 子问题完全独立 ⟹ 最优子结构成立。

枚举**第一步**的话，后续两段的代价还会相互影响（比如 Burst Balloons 里，
先扎破的气球会改变后面的邻居关系）⟹ 拆不开。

> **这是 LC-0312 和 LC-1547 的共同灵魂。** 记住这一点，两题就是同一道。

## 三个小节

### 01 - 区间博弈与分数差（LC-0486 Predict the Winner）

**状态定义的技巧**：`dp[i][j]` = **当前玩家在 `[i,j]` 上能领先对手多少分**。

```python
dp[i][j] = max(nums[i] - dp[i+1][j],      # 我拿左边，剩下的区间对手先选
               nums[j] - dp[i][j-1])      # 我拿右边
```

**为什么是减号**：`dp[i+1][j]` 是「**对手**在剩余区间的领先优势」，
对我来说就是劣势 ⟹ 取负。
**这个「分数差」的定义把两个玩家统一成了一个状态**，不用开两套 dp。

答案：`dp[0][n-1] >= 0`。

> 博弈类区间 DP 几乎都用这个「差值」技巧（LC-0877 Stone Game 同理）。

### 02 - 最后一步决策型

**LC-0312 Burst Balloons**：
```python
points = [1] + nums + [1]                # 两端补 1
dp[i][j] = max over k in (i,j) of
           dp[i][k] + dp[k][j] + points[i] * points[k] * points[j]
```
**k 是「最后一个被扎破的」** ⟹ 此刻 i 和 j 还在，所以乘的是 `points[i] * points[k] * points[j]`。

**LC-1547 Minimum Cost to Cut a Stick**：
```python
points = [0] + sorted(cuts) + [n]        # 两端补 0 和 n
dp[i][j] = min over k in (i,j) of
           dp[i][k] + dp[k][j] + (points[j] - points[i])
```
**k 是「这一段的最后一刀」**，代价是这一段的长度（不管 k 选哪个都一样）。

**两题共用的技巧：两端补哨兵**，让所有区间统一表达，不需要边界特判。

### 03 - Palindrome 区间 DP

**LC-0516 最长回文子序列**：
```python
s[i] == s[j] → dp[i][j] = dp[i+1][j-1] + 2
否则         → dp[i][j] = max(dp[i+1][j], dp[i][j-1])
```
**等价结论**：答案 = `LCS(s, reverse(s))` ⟹ 可以直接复用 LC-1143 的代码。

**LC-1312 最少插入次数使之成为回文**：
> ## **答案 = `n − LPS(s)`**

LPS 里的字符已经配好对不用动；剩下 `n − LPS` 个各补一个镜像即可。

> **「最少操作数 = n − 某个最优子结构」这个模式极其常见**：
> | 题 | 结论 |
> |---|---|
> | LC-1312 | `n − LPS` |
> | LC-0583 两串删除 | `m + n − 2·LCS` |
> | LIS 变体 | `n − LIS` |

## 不要和「回文**子串**」混
| | 子序列（本章 LC-0516） | 子串（LC-0005 / LC-0647） |
|---|---|---|
| 连续吗 | 不要求 | 要求 |
| 最优解法 | 区间 DP / LCS，O(n²) 空间 | **中心扩展**，O(n²) 时间 **O(1) 空间** |
| 位置 | 本章 | [02-two-pointers](<../../02-two-pointers (双指针)/04 - 回文与字符串双指针 (Palindrome)/02 - 中心扩展 (Expand Around Center)>) |

## 复杂度
| 转移类型 | 时间 | 空间 |
|---|---|---|
| 看两端（0516、1312、0486） | **O(n²)** | O(n²)（可滚动到 O(n)） |
| 枚举最后一步（0312、1547） | **O(n³)** | O(n²) |

**O(n³) 是枚举 k 带来的** —— 所以这类题的 n 通常很小（≤ 100～500）。

## 常见错误
- 遍历顺序错（大区间先算）⟹ 读到未初始化的状态。
- LC-0312 / LC-1547 忘记补哨兵。
- LC-0312 以为 k 是「第一个」被扎破的。
- LC-0486 的转移忘了负号。
- LC-1547 忘记先对 cuts 排序。

## 复习时的 Pattern Recognition
> 「区间 `[i,j]` 上的最优值」「操作顺序影响代价」「两个人轮流取」
> → 区间 DP。先问：**看两端，还是枚举最后一步？**
> 然后检查**遍历顺序**。
