# 12 · Dynamic Programming（动态规划）

> DP 题不靠背代码，靠**把状态定对**。本专题所有题都在回答三个问题：
> ## **① 状态是什么？② 转移怎么写？③ 遍历顺序能不能保证子问题先算完？**

本专题共 **72 道题** + 2 条跨专题索引，10 个 Level 1。

## 一、DP 的四步法（每道题都先走一遍）

1. **状态**：`dp[...]` 的下标代表什么，值代表什么。**一句话说不清就说明状态错了。**
2. **转移**：从哪些更小的状态推过来。
3. **初始化 / 边界**：`dp[0]` 是什么？空输入算几种方案？
4. **遍历顺序**：必须保证转移用到的状态**已经算完**。

**第 4 步是最容易出错的一步**，三个典型陷阱：
- **0-1 背包要倒序**，完全背包要正序（见 Level 1 `03`）。
- **区间 DP 要按区间长度从小到大**（或 `i` 倒序 + `j` 正序，见 Level 1 `08`）。
- 有些题**必须从终点倒推**（LC-0174 Dungeon Game，见 Level 1 `06`）。

## 三、八个必会模板

**T1 · 一维线性（Fibonacci 型）**
```python
dp[i] = f(dp[i-1], dp[i-2])          # 滚动成两个变量即可 O(1) 空间
```
复用：0509、0070、0746、0198（`dp[i] = max(dp[i-1], dp[i-2] + nums[i])`）。

**T2 · Kadane（最大连续子数组）**
```python
cur = max(x, cur + x)                # 「要么接上前面，要么从我重新开始」
best = max(best, cur)
```
**关键认知**：`cur` 是「以当前元素**结尾**的最大和」。
这个「以 i 结尾」的状态定义是连续子数组类题的通用起点。

**T3 · 0-1 背包（倒序）**
```python
for item in items:
    for j in range(capacity, item - 1, -1):      # ★ 倒序 = 每个物品只用一次
        dp[j] = max(dp[j], dp[j - item] + value)
```

**T4 · 完全背包（正序）**
```python
for item in items:
    for j in range(item, capacity + 1):          # ★ 正序 = 物品可重复用
        dp[j] = min(dp[j], dp[j - item] + 1)
```
> **倒序 vs 正序是背包唯一需要死记的东西。** 其他都能推。

**T5 · 双序列（LCS / 编辑距离）**
```python
s[i-1] == t[j-1] → dp[i][j] = dp[i-1][j-1] (+1)
否则             → dp[i][j] = min/max(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) (+1)
```
复用：1143、0072、0115、0010、0044、0718、0516（和自己的逆序做 LCS）。

**T6 · 区间 DP**
```python
for length in range(2, n + 1):               # ★ 小区间先算完
    for i in range(n - length + 1):
        j = i + length - 1
        dp[i][j] = min/max over k in (i, j) of  dp[i][k] + dp[k][j] + cost(i, k, j)
```
复用：0312（枚举最后扎破的气球）、1547（枚举最后一刀）、0516、1312、0486。

**T7 · 状态机（股票系列）**
```python
hold = max(hold, free - price)
free = max(free, hold + price)
```
**五道股票题就是这一个状态机加不同限制**，见 Level 1 `07`。

**T8 · LIS 的两种写法**
```python
# O(n²)：dp[i] = 以 i 结尾的 LIS 长度
# O(n log n)：tails[k] = 长度 k+1 的递增序列的最小结尾，用 bisect_left（严格递增）
```

| 模板 | 时间 | 空间 |
|---|---|---|
| T1 一维线性 | O(n) | O(1) |
| T2 Kadane | O(n) | O(1) |
| T3/T4 背包 | O(n · capacity) | O(capacity) |
| T5 双序列 | O(m·n) | O(n) 滚动 |
| T6 区间 DP | O(n³) | O(n²) |
| T7 状态机 | O(n) 或 O(n·k) | O(1) 或 O(k) |
| T8 LIS | O(n²) 或 **O(n log n)** | O(n) |

## 四、本专题最该记住的五条经验

**① 「以 i 结尾」往往比「前 i 个里的最优」更好定义。**
Kadane、LIS、0673 都靠这个。前者转移清晰，后者容易丢信息。

**② 返回值信息不足时，就返回元组 / 多开一维。**
- LC-0152 要同时维护 `max_prod` 和 `min_prod`（负数乘负数变正）。
- LC-0673 要同时维护 `dp[]` 和 `cnt[]`（**更优 ⟹ 重置，同优 ⟹ 累加**）。
- LC-0123 / 0188 要按交易次数多一维。

**③ 正推定义不出来，就试倒推。**
LC-0174 Dungeon Game：「从起点出发剩多少血」和「需要多少初始血」不等价，
正推没有自洽的最优子结构。**改成从终点倒推立刻变简单。**

**④ 「最少操作数」常常等于 `n − 某个最优子结构`。**
| 题 | 结论 |
|---|---|
| LC-1312 | 最少插入 = `n − LPS(s)` |
| LC-0583 | 最少删除 = `m + n − 2·LCS` |
| LIS 变体 | 最少删除使递增 = `n − LIS` |

**⑤ 无界的维度可以「封顶」。**
LC-0879 的利润是「至少 minProfit」，上界无穷 ⟹
`min(minProfit, p + profit)` 把它压成有界，状态数立刻可控。

## 五、什么时候**不**该用 DP

| 情况 | 该用什么 | 例子 |
|---|---|---|
| 要列出**所有方案** | 回溯 | LC-0078、LC-0046（见 [10-backtracking](<../10-backtracking (回溯)/README.md>)） |
| 贪心可证明最优 | 贪心 | LC-0122 无限次交易（但**加任何限制后贪心就错了**） |
| 连续子数组且全正数 | 滑动窗口 | 见 [03-sliding-window](<../03-sliding-window (滑动窗口)/>) |
| 需要「下一个更大/更小」 | 单调栈 | LC-0032 也能用栈做，见 [04-stack-queue](<../04-stack-queue (栈、队列)/>) |

**LC-0122 是个好警示**：无限次交易时贪心（所有上涨差之和）和 DP 等价；
但 LC-0123（最多 2 次）、LC-0309（冷却）、LC-0714（手续费）**贪心全都不成立**。
不要把一道题的贪心结论推广到整个系列。
