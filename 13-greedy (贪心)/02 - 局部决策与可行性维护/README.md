# Level 1 · 02 局部决策与可行性维护

## 核心定义
维护一个**资源状态**（油量、零钞、糖数、括号计数），每一步做一个局部决策。
贪心成立的理由通常是：**优先消耗「更不通用」的资源**，或者**某个局部失败能推出全局结论**。

## 01 - 环形资源平衡与起点选择（LC-0134 Gas Station）

**两个独立的结论**：
1. **有解判定**：`sum(gas) >= sum(cost)` ⟺ 存在可行起点。
2. **找起点**：一次扫描，`tank` 掉到负数时把候选起点跳到 `i + 1`。

```python
total = tank = start = 0
for i in range(n):
    diff = gas[i] - cost[i]
    total += diff
    tank += diff
    if tank < 0:            # 从 start 出发撑不到 i
        start = i + 1       # 候选起点直接跳到 i+1
        tank = 0
return start if total >= 0 else -1
```

**为什么可以直接跳到 `i + 1`（关键论证）**：
如果从 `start` 出发在 `i` 处油量首次变负，那么 `start..i` 之间**任何一点**作为起点
也撑不到 `i`（否则 tank 不会在 i 才变负 —— 中间任意前缀和都是非负的）。
⟹ 这一整段都可以跳过，每个位置只被扫一次 ⟹ **O(n)**。

## 02 - 局部资源使用与找零

### LC-0605 Can Place Flowers
扫描连续的 0 段，长度 L 的段能种 `(L - 1) // 2` 朵（两端的段算法略有不同）。
更简洁的写法：边扫边种，种下就把那个位置标记掉。

### LC-0860 Lemonade Change
只记两个计数器：有几张 **5**、几张 **10**（20 永远找不出去，不用记）。

**付 20 时优先用 `10 + 5` 而不是 `5+5+5`**。
**为什么**：10 元**只能**给付 20 的人找零；5 元**既能**给付 10 的、**也能**给付 20 的
⟹ **5 元更通用，要留着** ⟹ 能用 10 就先用 10。

> **「优先消耗更不通用的资源」是本章的核心直觉。**

## 03 - 合法候选过滤与条件合并（LC-1899 Merge Triplets）

**两步**：
1. **过滤**：只有「三个分量**都不超过** target 对应分量」的 triplet 才能用
   （否则用了它就会让某个分量永久超标 —— 操作只会取 max，不会变小）。
2. **合并**：对剩下的 triplet 逐分量取 max，看能否凑出 target。

**为什么可以无脑把所有合法 triplet 都合并**：取 max 是单调的，
多合并一个合法 triplet 只会让结果更接近 target，不会让它超标。
⟹ 不需要选择，全要就行。∎

## 04 - 双向局部约束与最小分配（LC-0135 Candy）

约束是**双向**的（比左邻居高要更多、比右邻居高也要更多）。
**一次扫描只能满足一个方向** ⟹ **扫两遍再取 max**：

```python
left[i]  = left[i-1] + 1  if ratings[i] > ratings[i-1]  else 1    # 从左到右
right[i] = right[i+1] + 1 if ratings[i] > ratings[i+1]  else 1    # 从右到左
answer = sum(max(left[i], right[i]))
```

**为什么取 max 同时满足两个方向**：两个数组各自满足一个方向的下界约束，
取 max 只会让值变大，**不会破坏任何下界** ⟹ 同时满足；而且是满足两者的**最小**值 ⟹ 总和最小。∎

> **「双向约束 ⟹ 正反各扫一遍再合并」是一个能直接复用的模式**：
> | 题 | 怎么用 |
> |---|---|
> | **LC-0135** 本题 | 左右各扫，取 **max** |
> | **LC-0042** Trapping Rain Water | 前缀最大、后缀最大，取 **min** |
> | **LC-0238** Product Except Self | 前缀积、后缀积，**相乘** |

LC-0135 也有 O(1) 空间的一次扫描解法（维护上坡/下坡长度，在坡顶结算），
但边界多，面试给两遍扫描版就够。

## 复杂度
全部 **O(n) 时间**；空间除 LC-0135 的两遍扫描版是 O(n) 外都是 O(1)。

## 常见错误
- LC-0134 只判了有解但返回的起点不对（必须边扫边跳）。
- LC-0860 多记一个 `twenty` 变量（没用），或者付 20 时优先用 5+5+5。
- LC-1899 忘了先过滤「某个分量超标」的 triplet。
- LC-0135 只扫一遍（只能满足一个方向）。
- LC-0135 取 min 而不是 max。

## 复习时的 Pattern Recognition
> 「环形走一圈，从哪开始」「能不能给每个人找零」「每个人至少 1 个且比邻居多」
> → 维护资源状态 + 局部决策。先问：
> **哪种资源更不通用？约束是单向还是双向？局部失败能推出什么全局结论？**
