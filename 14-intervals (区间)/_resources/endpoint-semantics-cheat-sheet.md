# Interval Endpoint Semantics Cheat Sheet（区间端点语义对照表）

> **本专题最重要的正确性文档。**
> 区间题 90% 的 WA 不是算法错，是**不等号差一个 `=`**。
> 铁律：**`[a, b]` 这种数组表示法本身不告诉你端点语义 —— 必须读题干。**

---

## 一、两种语义

### 【Closed Interval（闭区间）】`[a, b]`

`a` 和 `b` **都属于**区间。实际占用是 `a <= t <= b`。

**本专题的闭区间题**：
[LC-0986](<../02 - 双指针区间交集与多路合并/01 - 两个有序区间序列求交集/01 - LC-0986 - Interval List Intersections (学习索引 · 实体在 02-two-pointers)>)、
[LC-0452](<../03 - 不重叠区间与贪心调度/02 - 最少覆盖点与区间射击/01 - LC-0452 - Minimum Number of Arrows to Burst Balloons>)、
[LC-1851](<../05 - 离线区间查询与动态预订/01 - 最短覆盖区间的离线查询/01 - LC-1851 - Minimum Interval to Include Each Query>)、
[LC-2406](<../04 - 重叠计数、扫描线与资源分配/01 - 最少会议室与最大并发数/02 - LC-2406 - Divide Intervals Into Minimum Number of Groups>)、
[LC-1229](<../02 - 双指针区间交集与多路合并/01 - 两个有序区间序列求交集/02 - LC-1229 - Meeting Scheduler>)、
[LC-1109](<../04 - 重叠计数、扫描线与资源分配/02 - 差分事件与容量约束/03 - LC-1109 - Corporate Flight Bookings>)

```python
# 交集非空
max(a_start, b_start) <= min(a_end, b_end)      # ! <=
# 交集本身
[max(a_start, b_start), min(a_end, b_end)]
# 相交（等价写法）
a_start <= b_end and b_start <= a_end           # ! 两边都 <=
```

**端点相等仍然有交集**：`[1,2] ∩ [2,3] = [2,2]` —— **单点区间是合法交集**。
`[2,2]` 本身长度为 0，但它**非空**（含一个点 2）。
→ 这就是 LC-0986 里 `if left <= right` 不能写成 `<` 的原因。

### 【Half-open Interval（半开区间）】`[a, b)`

包含 `a`，**不包含** `b`。实际占用是 `a <= t < b`。长度恰好是 `b - a`。

**本专题的半开区间题**：
[LC-0729](<../05 - 离线区间查询与动态预订/02 - 在线插入与区间冲突检测/01 - LC-0729 - My Calendar I>)、
[LC-0731](<../05 - 离线区间查询与动态预订/02 - 在线插入与区间冲突检测/02 - LC-0731 - My Calendar II>)、
[LC-1094](<../04 - 重叠计数、扫描线与资源分配/02 - 差分事件与容量约束/01 - LC-1094 - Car Pooling>)、
[LC-1272](<../01 - 区间合并、插入与范围整理/02 - 区间包含与冗余消除/02 - LC-1272 - Remove Interval>)、
[LC-1288](<../01 - 区间合并、插入与范围整理/02 - 区间包含与冗余消除/01 - LC-1288 - Remove Covered Intervals>)（原题按半开讲，按闭区间做答案相同）

```python
# 相交
s1 < e2 and s2 < e1                             # ! 两边都是严格 <
# 不相交（反过来更好记）
e1 <= s2 or e2 <= s1                            # ! 「我整个在你前面，或你整个在我前面」
# 交集非空
max(s1, s2) < min(e1, e2)                       # ! <
```

`[10,20)` 和 `[20,30)` **没有冲突** —— 没有任何 `t` 同时满足两边。

## 二、一张总表（最该背的）

| 场景 | 闭区间 `[a,b]` | 半开区间 `[a,b)` |
|---|---|---|
| 相交条件 | `s1 <= e2 and s2 <= e1` | `s1 < e2 and s2 < e1` |
| 交集非空 | `max(s) <= min(e)` | `max(s) < min(e)` |
| 资源可复用 | `prev_end < cur_start` | `prev_end <= cur_start` |
| 差分数组撤销位置 | `diff[right + 1] -= v` | `diff[end] -= v` |
| 堆顶弹出条件 | `heap[0] < cur_start` | `heap[0] <= cur_start` |
| `[1,2]` vs `[2,3]` | **重叠**（都含 2） | **不重叠** |

> **记忆法**：闭区间「多含一个点」⟹ 判重叠时**更宽松**（`<=`），
> 释放资源时**更严格**（`<`），差分撤销**往后挪一格**（`right+1`）。
> 半开区间全部相反。

## 三、Meeting Scheduling（会议室语义）

会议在**结束时刻立即释放房间**，所以会议时间天然是半开区间 `[start, end)`：

```python
previous_end <= current_start      # ! 可以复用同一间房
```

**本专题的直接对照**（同一个算法，不等号差一个 `=`）：

| 题 | 区间 | 复用条件 | 堆弹出 | 差分 |
|---|---|---|---|---|
| [LC-0252 Meeting Rooms](<../03 - 不重叠区间与贪心调度/01 - 冲突检测与最大兼容区间数量/01 - LC-0252 - Meeting Rooms>) | 半开 | `prev_end <= start` | — | — |
| [LC-0253 Meeting Rooms II](<../04 - 重叠计数、扫描线与资源分配/01 - 最少会议室与最大并发数/01 - LC-0253 - Meeting Rooms II>) | 半开 | `heap[0] <= start` | `<=` | `diff[end] -= 1` |
| [LC-2406 Divide Intervals](<../04 - 重叠计数、扫描线与资源分配/01 - 最少会议室与最大并发数/02 - LC-2406 - Divide Intervals Into Minimum Number of Groups>) | **闭** | `heap[0] < left` | `<` | `diff[right+1] -= 1` |

> **LC-0253 和 LC-2406 是同一道题的两种端点语义版本。**
> 把 253 的代码原样抄到 2406，会在 `[[1,2],[2,3]]` 上答 1（正确是 2）。

## 四、Difference Array（差分数组）的撤销位置

对区间整体加 `v`：

```python
# 半开 [start, end)
diff[start] += v
diff[end]   -= v          # ! end 位置已经不在区间内 ⟹ 就在 end 撤销

# 闭 [left, right]
diff[left]      += v
diff[right + 1] -= v      # ! right 还在区间内 ⟹ 要到 right+1 才撤销
```

**离散整数 + 右端点包含在内 ⟹ 必须在 `right + 1` 处撤销。**
数组因此要多开一格（`[0] * (n + 1)`），否则 `IndexError`。

**1-based 编号的额外陷阱**（见
[LC-1109](<../04 - 重叠计数、扫描线与资源分配/02 - 差分事件与容量约束/03 - LC-1109 - Corporate Flight Bookings>)）：
航班编号 `1..n`、数组下标 `0..n-1`，闭区间 `[first, last]` 对应
```python
diff[first - 1] += v      # ! 下标减 1
diff[last]      -= v      # ! (last-1)+1 == last，看起来不对称，其实两个偏移抵消了
```

## 五、事件排序（Sweep Line）的 tie-break

同一坐标上「开始」和「结束」谁先处理，**取决于端点语义，而且会改变答案**：

| 想要的语义 | 排序键 | 效果 |
|---|---|---|
| 半开 / 端点相接**不**算重叠 | `(pos, delta)`（**`-1` 在前**） | 先释放再占用 ⟹ 并发数不虚高 |
| 闭 / 端点相接**算**重叠 | `(pos, -delta)`（**`+1` 在前**） | 先占用再释放 ⟹ 共享端点被计为重叠 |

实例：
- [LC-1094 Car Pooling](<../04 - 重叠计数、扫描线与资源分配/02 - 差分事件与容量约束/01 - LC-1094 - Car Pooling>)
  用 `(pos, delta)` —— 同一站先下车后上车，否则误判超载。
- [LC-0759 Employee Free Time](<../02 - 双指针区间交集与多路合并/02 - 多人时间表与公共空闲区间/01 - LC-0759 - Employee Free Time>)
  用 `(pos, -delta)` —— 否则 `[1,2]` 与 `[2,3]` 之间会冒出一个零长度「空闲」。

## 六、六个必测边界（每道新题都要过一遍）

| # | 边界 | 具体例子 | 为什么能抓 bug |
|---|---|---|---|
| 1 | **端点相等** | `[1,2]` vs `[2,3]` | 直接暴露 `<` / `<=` 写错 |
| 2 | **完全包含** | `[1,10]` vs `[2,3]` | 暴露只比较 start 或只比较 end 的逻辑 |
| 3 | **完全相同** | `[1,2]` vs `[1,2]` | 暴露排序 tie-break 和去重 |
| 4 | **零长度交集** | `[1,2] ∩ [2,3] = [2,2]` | 闭区间要保留，半开要丢弃 |
| 5 | **空输入** | `[]` | 暴露 `intervals[0]` 的越界 |
| 6 | **完全无重叠** | `[[1,2],[5,6]]` | 暴露「假设一定有重叠」的分支 |

额外补充（按题目约束）：
- 单元素输入 `[[1,1]]`（闭区间的零长度区间）
- 负数坐标 `[[-5,-4]]`
- 输入**未排序**（LC-1229 不保证有序！）
- 组内相邻但不相接 vs 相接（LC-1272）
- 被拒绝的操作**不能污染状态**（LC-0729 / LC-0731）
- 峰值**恰好等于**容量上限（`<=` 不是 `<`，LC-1094）

## 七、读题时的三问

1. **端点算不算在区间内？**（闭 / 半开 / 开）
2. **「相邻」和「相交」在本题算同一回事吗？**
   （`[1,2]` 与 `[2,3]`：Merge Intervals 要合并，My Calendar 不冲突）
3. **要的是「并集」「交集」「差集」还是「覆盖数」？**
   四个目标用的排序键和不等号都不同 —— 见
