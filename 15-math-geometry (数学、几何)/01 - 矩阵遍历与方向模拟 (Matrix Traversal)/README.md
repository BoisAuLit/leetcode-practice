# Level 1 · 01 — 矩阵遍历与方向模拟（Matrix Traversal）

> **本层的统一目标：按一个「非行优先」的顺序走遍矩阵，且每个格子恰好走一次。**
> 难点从来不是算法，而是**边界什么时候收缩**和**方向什么时候切换**。
>
> **Level 2 · 03 是这一层的延伸**：把方向向量**从矩阵里拿出来**单独用。
> 没有网格、没有边界，只剩旋转本身的代数性质 —— 90° 旋转的**阶是 4**。

---

## 核心定义

| 术语 | 定义 |
|---|---|
| **Boundary Traversal（边界遍历）** | 用 `top / bottom / left / right` 四个变量界定「还没走过的矩形」 |
| **Spiral Traversal（螺旋遍历）** | 一圈圈向内走；每走完一条边就把该边从矩形里移除 |
| **Direction Simulation（方向模拟）** | 用方向向量数组 + `d = (d+1) % 4` 来「转弯」 |
| **Diagonal Traversal（对角线遍历）** | 按 `r + c`（主对角线族）或 `r - c`（副对角线族）分组 |
| **Coordinate Validation（坐标合法性）** | `0 <= nr < m and 0 <= nc < n`，每次移动都要查 |
| **Rotation Order（旋转的阶）** | 把方向转 `k` 次回到原方向的最小 `k`。90° 旋转的阶是 **4** ⟹ `I + R + R² + R³ = 0` |

---

## 三个决定性观察

### ① 螺旋遍历的本质是「矩形在收缩」

不要把它想成「转圈」，而是：

> 维护一个**还没走过的子矩形** `[top, bottom] × [left, right]`。
> 每走完一条边，就把那条边**从矩形里切掉**。
> 矩形为空（`top > bottom` 或 `left > right`）时结束。

这样「每个格子恰好一次」是**自动成立**的，不需要 `visited` 数组。

### ② ③④ 两条边必须先检查边界，①② 不用

进入 `while` 时已保证矩形非空 ⟹ ①（上边）②（右边）一定安全。
但 ① 做了 `top += 1`、② 做了 `right -= 1` 之后，**矩形可能已经空了**：

| 退化情形 | 走完①② 后 | 不检查③④ 会怎样 |
|---|---|---|
| **单行** `1 × n` | `top > bottom` | ③ 把这一行**倒着再走一遍** ❌ |
| **单列** `m × 1` | `left > right` | ④ 把这一列**倒着再走一遍** ❌ |

**反例** `[[1,2,3]]`：① 输出 `1,2,3`，`top` 变成 1 > `bottom`=0。
③ 若不检查 ⟹ 继续输出 `2,1` ⟹ 结果 `1,2,3,2,1` ❌。

> **一句话**：①② 消费的是「必定存在」的边；
> ③④ 消费的边**可能和①②是同一条**。
> 这是整个 Level 1 最高频的 bug。

### ③ 对角线遍历的分组不变量：`r + c` 恒定

同一条**副对角线**（从右上到左下）上的所有格子，`r + c` 是同一个值。
`m × n` 矩阵一共有 `m + n - 1` 条这样的对角线，编号 `s = 0 .. m+n-2`。

LC-0498 要求**交替方向**：
- `s` 为**偶数** ⟹ 从左下往右上走（`r` 减、`c` 加）
- `s` 为**奇数** ⟹ 从右上往左下走（`r` 加、`c` 减）

这样相邻两条对角线首尾相接，形成一条连续的「之」字路径。

---

## 核心不变量

**螺旋（LC-0054 / 0059 / 2326）**：
> 任意时刻，`[top, bottom] × [left, right]` 内的格子**都还没被访问**，
> 其外的格子**都已被访问**。

**方向模拟（LC-0885）**：
> 不管当前走到哪，`steps` 序列 `1,1,2,2,3,3,…` 保证螺旋路径
> **覆盖以起点为中心的、越来越大的同心正方形环**
> ⟹ 只要收集到 `m*n` 个合法格子就一定走完了。

**对角线（LC-0498）**：
> 处理第 `s` 条对角线时，前 `s` 条已经完整输出，
> 且输出顺序与 `s` 的奇偶一致。

---

## 为什么这样设计遍历顺序

| 题 | 走法 | 为什么 |
|---|---|---|
| LC-0054 Spiral Matrix | 四边界 + 收缩 | 不需要 `visited`，O(1) 额外空间 |
| LC-0059 Spiral Matrix II | **同一套**四边界，只是写入 | **Read 和 Write 共享同一个遍历骨架** |
| LC-2326 Spiral Matrix IV | **同一套**四边界，从链表取值 | 链表走完就填 `-1` |
| LC-0498 Diagonal Traverse | 按 `r+c` 分组 + 交替方向 | 分组后天然不重复 |
| LC-0885 Spiral Matrix III | 方向向量 + 步长 `1,1,2,2,3,3,…` | 起点可以在**矩阵外**，四边界法不适用 |

### LC-0054 / 0059 / 2326：**不要记三套螺旋算法**

```
LC-0054：  result.append(matrix[r][c])      ← 读
LC-0059：  matrix[r][c] = counter; counter += 1   ← 写
LC-2326：  matrix[r][c] = node.val if node else -1  ← 从链表写
```
**遍历骨架一字不改**，只有循环体里那一行不同。
这是本专题「少记忆、多迁移」的最佳例子。

### LC-0885 为什么不能用四边界法

起点 `(rStart, cStart)` 可以在矩阵的任意位置，螺旋会**走到矩阵外面**再回来。
「还没走过的子矩形」这个模型不成立了 ⟹ 必须换成
**方向向量 + 递增步长**，并对每一步做坐标合法性检查，只收集界内的。

**步长为什么是 `1,1,2,2,3,3,…`？**
螺旋每走两条边，边长就 +1（向右 1 → 向下 1 → 向左 2 → 向上 2 → 向右 3…）。
**总步数是 O((m+n)²)**，而收集到的格子只有 `m·n` —— 界外的空转是必要代价。

---

## 简短正确性证明

### 螺旋遍历每个格子恰好访问一次

四个边界构成闭区间矩形 `R = [top,bottom] × [left,right]`。
每轮循环：① 输出 `R` 的上边后 `top += 1`，②③④ 同理。
每条边输出后**立刻从 `R` 中移除** ⟹
- **不重复**：移除后的格子不再属于 `R`，而所有输出都取自 `R` 的边界。
- **不遗漏**：`R` 每轮至少缩小一行或一列，有限步后为空；为空意味着所有格子都被移除过，即都输出过。

总输出 = `m × n` ⟹ **O(m·n)** 时间、**O(1)** 额外空间（不计输出）。∎

### 对角线遍历不重不漏

映射 `(r, c) → s = r + c` 把 `m × n` 个格子划分成 `m+n-1` 个**互不相交**的等价类
（每个格子的 `s` 唯一）。逐 `s` 输出 ⟹ 不重不漏。∎

## Python 模板

### Template 1：Matrix Spiral Boundary Traversal

```python
def spiralOrder(matrix):
    m, n = len(matrix), len(matrix[0])
    top, bottom, left, right = 0, m - 1, 0, n - 1
    res = []
    while top <= bottom and left <= right:
        for c in range(left, right + 1):            # ① 上边：左 → 右
            res.append(matrix[top][c])
        top += 1                                     # !   立刻收缩
        for r in range(top, bottom + 1):             # ② 右边：上 → 下
            res.append(matrix[r][right])
        right -= 1
        if top <= bottom:                            # ! ⚠️ 单行时必须拦住
            for c in range(right, left - 1, -1):     # ③ 下边：右 → 左
                res.append(matrix[bottom][c])
            bottom -= 1
        if left <= right:                            # ! ⚠️ 单列时必须拦住
            for r in range(bottom, top - 1, -1):     # ④ 左边：下 → 上
                res.append(matrix[r][left])
            left += 1
    return res
```
**O(m·n)** 时间、**O(1)** 额外空间。
**LC-0059 / LC-2326 把 `res.append(...)` 换成写入即可，骨架不动。**

### 对角线遍历（LC-0498）

```python
def findDiagonalOrder(mat):
    m, n = len(mat), len(mat[0])
    res = []
    for s in range(m + n - 1):                       # ! s = r + c
        if s % 2 == 0:                               # ! 偶数：左下 → 右上
            r = min(s, m - 1)                        # ! 起点贴着左/下边界
            c = s - r
            while r >= 0 and c < n:
                res.append(mat[r][c]); r -= 1; c += 1
        else:                                        # ! 奇数：右上 → 左下
            c = min(s, n - 1)
            r = s - c
            while c >= 0 and r < m:
                res.append(mat[r][c]); r += 1; c -= 1
    return res
```
**O(m·n)** 时间、O(1) 额外空间。
`r = min(s, m-1)` 是起点的关键：`s` 小的时候起点在第 `s` 行，`s` 大了之后被 `m-1` 卡住。

### 方向向量 + 递增步长（LC-0885）

```python
DIRS = ((0, 1), (1, 0), (0, -1), (-1, 0))            # ! 右 下 左 上（顺时针）
def spiralMatrixIII(rows, cols, rStart, cStart):
    res, r, c, d, step = [], rStart, cStart, 0, 1
    res.append([r, c])
    while len(res) < rows * cols:
        for _ in range(2):                           # ! 每个步长用两次
            dr, dc = DIRS[d]
            for _ in range(step):
                r += dr; c += dc
                if 0 <= r < rows and 0 <= c < cols:  # ! 只收界内的
                    res.append([r, c])
            d = (d + 1) % 4                          # ! 转 90°
        step += 1                                    # ! 每两条边步长 +1
    return res
```
**O((rows+cols)²)** 时间（含界外空转）、O(1) 额外空间。

| 题 | 时间 | 空间 | 说明 |
|---|---|---|---|

| LC-0059 | **O(n²)** | O(n²) 输出 | 生成 `n × n` |
| LC-2326 | **O(m·n)** | O(m·n) 输出 | 链表更短时提前填 `-1` |
| LC-0498 | **O(m·n)** | O(1) 额外 | 按 `r+c` 分组 |

## 典型边界情况

| 边界 | 例子 | 期望 |
|---|---|---|
| **单行** | `[[1,2,3]]` | `[1,2,3]`（**不能**是 `[1,2,3,2,1]`） |
| **单列** | `[[1],[2],[3]]` | `[1,2,3]` |
| **1×1** | `[[7]]` | `[7]` |
| **非正方形** | `3 × 4` / `4 × 3` | 四边界法无需改动 |
| **2×2** | `[[1,2],[3,4]]` | `[1,2,4,3]` |
| 全部元素相同 | `[[5,5],[5,5]]` | 顺序仍要对（长度必须是 4） |
| 收缩后越界 | `2 × 3` 走完第一圈 | ③④ 的检查生效 |
| LC-2326 链表比矩阵短 | `m*n = 6`，链表 4 个 | 剩下两格填 `-1` |
| LC-0885 起点在角上 | `rStart=0, cStart=0` | 大量界外空转 |
| LC-0498 的 `s` 边界 | `s = 0` 和 `s = m+n-2` | 起点的 `min(s, m-1)` |

## 常见错误与反例

| 错误做法 | 反例 | 结果 |
|---|---|---|
| ③④ 不检查 `top <= bottom` / `left <= right` | `[[1,2,3]]` | `[1,2,3,2,1]` ❌ 重复 |
| 走完一条边**忘记收缩**边界 | 任意 2×2 以上 | 死循环或重复访问 |
| 用 `visited` 数组代替收缩 | — | 能跑对，但白费 O(m·n) 空间 |
| LC-0059 另写一套螺旋逻辑 | — | 两套代码两倍 bug；骨架应复用 LC-0054 |
| LC-0498 用 `r - c` 分组 | — | 分组没错，但方向和起点公式全变，更难写 |
| LC-0498 起点写成 `r = s` | `s >= m` 时 | 越界 —— 必须 `min(s, m-1)` |
| LC-0885 用四边界法 | 起点在矩阵中间 | 模型不成立，螺旋会走到界外 |
| LC-0885 声称 O(rows·cols) | — | 实际是 O((rows+cols)²) |
| 方向移动后**不检查**坐标合法性 | 任意 | `IndexError` 或 Python 的负索引静默回绕 ⚠️ |

> ⚠️ **Python 的负索引特别危险**：`matrix[-1][0]` **不报错**，
> 它悄悄访问最后一行。所以坐标检查必须写 `0 <= nr < m`，
> **不能只写 `nr < m`**。

## Level 2 · 03 — 方向向量旋转与周期性判断

> **这一层只有一道题（LC-1041），但它回答了一个前面所有螺旋题都在用、却没人证明过的问题：
> 「转 4 次就回到原方向」凭什么成立，以及这件事能推出什么。**

### 判据：有界 ⟺ 净位移为零 **或** 朝向改变

走完**一遍**指令后，记净位移 `v`、相对初始朝向的旋转 `R`：

| 情形 | k 遍之后在哪 | 结论 |
|---|---|---|
| `R == I`（朝向没变） | `k · v` | `v == 0` → 永远在原点；`v != 0` → **线性发散** |
| `R == ` 180° | `v + Rv = 0`（第 2 遍回原点） | **有界** |
| `R == ` 90° / 270° | `v + Rv + R²v + R³v = 0`（第 4 遍回原点） | **有界** |

```python
return (x == 0 and y == 0) or (dx, dy) != (0, 1)
```

### 为什么 `I + R + R² + R³ = 0`

`R` 是 90° 旋转，`R⁴ = I`，且 `R != I`。于是

```
(I - R)(I + R + R² + R³) = I - R⁴ = 0
```

而 `I - R` 可逆（`R` 没有特征值 1，因为 90° 旋转不保持任何非零向量不动）
⟹ `I + R + R² + R³ = 0`。∎

**180° 的情形更直接**：`R = -I`，所以 `I + R = 0`，两遍就闭合。

> 这就是「模拟 4 遍再看是否回原点」这个朴素做法的**正确性来源**。
> 知道它之后，代码从 4 遍降到 1 遍 —— 而这一层真正的收获是：
> **「周期性」可以用旋转的阶直接算出来，不必靠模拟去碰**。

### 和本层其他题共享的机制

| | 方向向量 | 转向方式 | 有没有网格边界 |
|---|---|---|---|
| LC-0054 / 0059 / 2326 | 四边界隐含 | 走完一条边就切掉 | 有（矩形收缩） |
| LC-0885 | `dirs[4]` + `d = (d+1) % 4` | 步长递增时转 | 有（但允许走到界外） |
| **LC-1041** | `(dx, dy) = (-dy, dx)` | 指令驱动 | **没有** ⟹ 只剩代数 |

**旋转公式一定要手验一次**：`(0,1) → (-1,0)` 是左转（北 → 西）。
写反只会让左右互换，而题目对左右是**对称**的 ⟹ **测试照样全绿**，靠测试兜不住这个错。
