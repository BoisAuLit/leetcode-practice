# Level 1 · 02 — 矩阵变换与状态模拟（Matrix Transformation）

> **本层的统一目标：改变矩阵的内容或布局 —— 而「什么时候能安全覆盖」是全部难点。**
> Level 01 只读不写；本层开始写，于是「写入顺序」第一次变成正确性问题。

---

## 核心定义

| 术语 | 定义 |
|---|---|
| **Coordinate Transformation（坐标变换）** | 一个纯映射 `(r, c) → (r', c')`；转置、旋转、翻转都是它 |
| **In-place Matrix Modification（原地修改）** | 不开新矩阵，O(1) 额外空间 |
| **In-place Marking（原地标记）** | 把「要做什么」的信息**存进矩阵自己的格子里** |
| **Simultaneous State Update（同步状态更新）** | 新状态只依赖**旧**状态 ⟹ 必须两阶段 |
| **Multi-phase Simulation（多阶段模拟）** | 标记 → 消除 → 重力 → 重复，每阶段独立一个 pass |

---

## 三个决定性观察

### ① 原地旋转只对**正方形**成立

`m × n` 矩阵旋转 90° 后变成 `n × m` —— **形状都变了**，不可能原地。

| 题 | 形状 | 能原地吗 |
|---|---|---|
| [LC-0867 Transpose](<./01 - 转置与矩阵旋转/01 - LC-0867 - Transpose Matrix>) | `m × n` 任意 | ❌（题目也不要求） |
| [LC-0048 Rotate Image](<./01 - 转置与矩阵旋转/02 - LC-0048 - Rotate Image>) | **`n × n` 正方形** | ✅（题目要求） |
| [LC-1861 Rotating the Box](<./03 - 多轮矩阵消除与重力模拟/02 - LC-1861 - Rotating the Box>) | `m × n` 矩形 | ❌ 必须开新矩阵 |

**正方形的原地旋转 = 转置 + 翻转每一行**：
```python
for r in range(n):
    for c in range(r + 1, n):               # ! c 从 r+1 开始，只走上三角
        matrix[r][c], matrix[c][r] = matrix[c][r], matrix[r][c]
for row in matrix:
    row.reverse()
```
**为什么 `c` 从 `r+1` 开始？** 从 0 开始会把每对元素交换**两次**（等于换回去了）。
只走上三角 ⟹ 每对恰好一次。

**逆时针 90°** = 转置 + **上下**翻转（`matrix.reverse()`）。

### ② 新状态依赖旧状态 ⟹ **必须两阶段**，这是本层的核心模式

```
Read Original State  →  Record Updates  →  Apply Updates
```

**这是本质，不是技巧。** [LC-0073](<./02 - 原地标记与同步状态更新/01 - LC-0073 - Set Matrix Zeroes (学习索引 · 实体在 01-arrays-hashing)>)
和 [LC-0289](<./02 - 原地标记与同步状态更新/02 - LC-0289 - Game of Life>) 是同一个模式的两道题。

**LC-0073 的反例**：
```
1 0        正确：0 0        边扫边清：0 0
1 1              1 0                  0 0   ❌
```
扫到 `(0,1)` 的 0 就清第 0 行和第 1 列 ⟹ `(1,1)` 变 0
⟹ 继续扫到它又去清第 1 行 ⟹ `(1,0)` 也没了 ⟹ **全盘崩塌**。

**LC-0289 的反例**（横向 blinker `[[1,1,1],[0,0,0],[0,0,0]]`）：

| 格子 | 正确（读原始状态） | 行优先直接覆盖 |
|---|---|---|
| `(0,0)` | 活邻居 1 ⟹ **死**，记下但不写 | 死，**立刻写回 0** |
| `(0,1)` | 活邻居 `(0,0)`、`(0,2)` = 2 ⟹ **继续活** | 读到 `(0,0)` 已是 0 ⟹ 只剩 1 个 ⟹ **错判为死** ❌ |

正确答案 `[[0,1,0],[0,1,0],[0,0,0]]`（blinker 转 90°），
直接覆盖得到**全 0** —— 整个图案消失。

### ③ 标记存在哪，决定了「顺序」要不要操心

| 标记位置 | 例子 | 顺序敏感吗 |
|---|---|---|
| **和数据挤同一个格子** | LC-0073（第一行/第一列） | ✅ **非常敏感** |
| **和数据住不同 bit** | LC-0289（高位 bit） | ❌ 完全不敏感 |
| 另开一份快照 | LC-0289 解法 2 | ❌ |

> **LC-0289 的位编码更干净**：第 0 位存旧状态、第 1 位存新状态，
> 两者天然不互相污染，所以第一遍可以任意顺序扫。
> **LC-0073 的标记挤占了数据位**，所以必须靠顺序保证正确。
> **两题一起看，才能明白「原地算法」的真正难点是「什么时候能安全覆盖」。**

## 核心不变量

**坐标变换（LC-0867 / 0048）**：
> 映射是**双射** ⟹ 每个元素恰好被搬一次，不会丢也不会重。

**同步更新（LC-0073 / 0289）**：
> 第一阶段结束前，**任何格子的「原始信息」都还可读**。
> （LC-0073：原始的 0 信息已被安全提取到第一行/列；
>  LC-0289：第 0 位从未被修改。）

**位编码（LC-0289）**：
> 第一遍只做 `|= 2`（只动高位）⟹ `x & 1` 永远返回原始状态。
> 第二遍统一 `>>= 1` 兑现新状态。

**多阶段模拟（LC-0723）**：
> 每一轮内部：**先全盘标记，再统一消除，最后统一下落**。
> 任意一个阶段都不能和另一个交错，否则会用到中间态。

**重力双指针（LC-1861）**：
> `write` 永远指向「下一个石头该落的位置」；
> 遇到障碍 `'*'` 就把 `write` 重置到它**左边**（该段结算完毕）。

## 简短正确性证明

### LC-0048 的「转置 + 翻转 = 顺时针 90°」

顺时针 90° 的映射是 `(r, c) → (c, n-1-r)`。
- **转置**：`(r, c) → (c, r)`
- **再左右翻转每一行**：`(c, r) → (c, n-1-r)`

复合起来正好是 `(r, c) → (c, n-1-r)` ∎

**验证**（`[[1,2],[3,4]]`）：
```
原始     转置     翻转每行
1 2      1 3      3 1
3 4      2 4      4 2
```
顺时针 90° 的答案就是 `[[3,1],[4,2]]` ✓
（**原矩阵的第一列从下往上读，变成新矩阵的第一行**。）

### LC-0289 的位编码为什么安全

设第一遍结束时格子的值是 `v = old + 2·new`（`old, new ∈ {0,1}`）。
- 读旧状态：`v & 1 = old`（因为 `2·new` 的第 0 位恒为 0）✓
- 第一遍只做 `v |= 2`，**不改第 0 位** ⟹ 后续格子读到的 `old` 仍是原始值 ✓
- 第二遍 `v >>= 1` 得到 `new` ✓ ∎

### LC-1861 为什么「先沉降后旋转」

旋转 90° 后的「向下」对应原矩阵的「**向右**」。
所以在原矩阵里把每一行的石头往右推，再旋转，等价于「旋转后让石头下落」。
**好处**：行内沉降是**独立的一维问题**，旋转是**纯坐标变换**
⟹ **两件事解耦**，各自都已经会做。∎

## Python 模板

### Template 2：Matrix Transpose + Reverse（原地旋转正方形）

```python
def rotate(matrix):                              # LC-0048，顺时针 90°，原地
    n = len(matrix)
    for r in range(n):
        for c in range(r + 1, n):                # ! 只走上三角
            matrix[r][c], matrix[c][r] = matrix[c][r], matrix[r][c]
    for row in matrix:
        row.reverse()
```
**O(n²)** 时间、**O(1)** 额外空间。

### 矩形转置 / 旋转（必须新建）

```python
transpose = [[mat[r][c] for r in range(m)] for c in range(n)]       # LC-0867: n×m
rotated   = [[mat[m - 1 - c][r] for c in range(m)] for r in range(n)]  # 顺时针: n×m
```
**O(m·n)** 时间与空间。

### Template 3：In-place Matrix Marking（LC-0073）

```python
first_col_zero = any(matrix[i][0] == 0 for i in range(m))   # ! 第 0 列单独记
for i in range(m):                                # ! ① 只写标记，不清数据
    for j in range(1, n):
        if matrix[i][j] == 0:
            matrix[i][0] = 0                      # ! 行标记 → 第一列
            matrix[0][j] = 0                      # ! 列标记 → 第一行
for i in range(1, m):                             # ! ② 回填内部（读标记，不改标记）
    for j in range(1, n):
        if matrix[i][0] == 0 or matrix[0][j] == 0:
            matrix[i][j] = 0
if matrix[0][0] == 0:                             # ! ③ 最后才处理第 0 行
    for j in range(n): matrix[0][j] = 0
if first_col_zero:                                # ! ④ 和第 0 列
    for i in range(m): matrix[i][0] = 0
```
**O(m·n)** 时间、**O(1)** 额外空间。
**`matrix[0][0]` 一个格子存不下「第 0 行」和「第 0 列」两个 bit ⟹ 必须额外一个变量。**

### Template 4：Simultaneous State Update（LC-0289 位编码）

```python
for r in range(m):                                # ! ① 第 0 位 = 旧，第 1 位 = 新
    for c in range(n):
        live = 0
        for dr in (-1, 0, 1):
            for dc in (-1, 0, 1):
                if dr == 0 and dc == 0:
                    continue
                nr, nc = r + dr, c + dc
                if 0 <= nr < m and 0 <= nc < n:
                    live += board[nr][nc] & 1      # ! 只读第 0 位 ⟹ 永远是原始状态
        old = board[r][c] & 1
        if (old and live in (2,3)) or (not old and live == 3):
            board[r][c] |= 2                       # ! 只写第 1 位
for r in range(m):                                 # ! ② 统一兑现
    for c in range(n):
        board[r][c] >>= 1
```
**O(m·n)** 时间、**O(1)** 额外空间。

### 重力双指针（LC-1861）

```python
for r in range(m):
    write = n - 1
    for read in range(n - 1, -1, -1):
        if box[r][read] == '*':
            write = read - 1                       # ! 障碍：落点重置到它左边
        elif box[r][read] == '#':
            box[r][read] = '.'                     # ! ⚠️ 先清源
            box[r][write] = '#'                    # ! ⚠️ 再写目标
            write -= 1
```
**O(m·n)** 时间。
**顺序写反，当 `read == write` 时石头会凭空消失**（反例 `[["#"]]`）。

## 复杂度

| 题 | 时间 | 额外空间 | 说明 |
|---|---|---|---|
| LC-0867 | O(m·n) | O(m·n) 输出 | 形状变化，必须新建 |
| LC-0048 | **O(n²)** | **O(1)** | 正方形才能原地 |
| LC-0073 | O(m·n) | **O(1)** | 解法 B；解法 A 是 O(m+n) |
| LC-0289 | O(m·n) | **O(1)** | 位编码；稀疏版是 O(k) |
| LC-0723 | **O((m·n)²)** | O(1) | ⚠️ 最多 `m·n` 轮，每轮 O(m·n) |
| LC-1861 | O(m·n) | O(m·n) 输出 | 矩形旋转必须新建 |

> ⚠️ **LC-0723 不是 O(m·n)**：每一轮至少消掉 3 个糖，
> 所以最多 `m·n/3` 轮，每轮扫一遍 ⟹ **O((m·n)²)**。
> 把它写成 O(m·n) 是错的。

## 典型边界情况

| 边界 | 例子 | 期望 |
|---|---|---|
| **1×1** | `rotate([[1]])` | `[[1]]` |
| **非正方形** | `transpose(3×4)` | `4×3` |
| 单行 / 单列 | `rotate` 不适用（非正方形） | — |
| 全部元素相同 | `[[5,5],[5,5]]` | 变换后仍全 5 |
| LC-0073 第一行就有 0 | `[[0,1],[1,1]]` | 标记区本身被污染 |
| LC-0073 第一列就有 0 | `[[1,1],[0,1]]` | `first_col_zero` 的用处 |
| LC-0073 `matrix[0][0] == 0` | `[[0,1],[1,1]]` | 行列标记冲突 |
| LC-0289 单格活 | `[[1]]` | `[[0]]`（0 个邻居 ⟹ 死） |
| LC-0289 2×2 全活 | `[[1,1],[1,1]]` | **不变**（每个都有 3 个活邻居） |
| LC-0289 角落格子 | 邻居不足 8 个 | 坐标检查必须生效 |
| LC-1861 单石头 | `[["#"]]` | `[["#"]]`（`read == write` 的试金石） |
| LC-1861 障碍切段 | `[["#","*","#"]]` | 两段各自独立沉降 |
| 多次更新后一致性 | 连续跑两代 LC-0289 | 第二代必须基于第一代的最终状态 |

## 常见错误与反例

| 错误做法 | 反例 | 结果 |
|---|---|---|
| LC-0073 边发现 0 边清行列 | `[[1,0],[1,1]]` | 全盘变 0 ❌ |
| LC-0073 先清第 0 行再回填内部 | 任意第 0 行有标记的用例 | 列标记全丢 ❌ |
| LC-0073 不用 `first_col_zero` | `matrix[0][0] == 0` | 第 0 行和第 0 列分不清 ❌ |
| LC-0289 边扫边覆盖 | `[[1,1,1],[0,0,0],[0,0,0]]` | 得全 0，正确是 blinker 转 90° ❌ |
| LC-0289 用 `board[nr][nc]` 而非 `& 1` | 任意 | 把 `2`（新活）当成活邻居 ⟹ 计数错 ❌ |
| LC-0289 忘了第二遍 `>>= 1` | 任意 | 矩阵里留着 2 和 3，不是合法 0/1 ❌ |
| LC-0048 两层循环都从 0 开始 | 任意 n ≥ 2 | 每对交换两次 = 没换 ❌ |
| LC-0048 对非正方形用原地法 | `3 × 4` | 形状不匹配，`IndexError` ❌ |
| LC-1861 先写目标再清源 | `[["#"]]` | 石头消失 ❌ |
| LC-1861 先旋转再按列沉降 | — | 能对，但索引更绕、更易错（见 `Solution_2`） |
| LC-0723 把三个阶段交错 | — | 用到中间态，消除判定错 ❌ |
| LC-0723 声称 O(m·n) | — | 实际 O((m·n)²) ❌ |
