# Level 1 · 04 — 坐标几何与空间计数（Geometry / Coordinate Counting）

> **本层的统一目标：把几何问题转化成「坐标比较」或「Hash Map 计数」—— 全程不用浮点。**
> 本专题刻意**不做** Computational Geometry（凸包、FFT、高级数论）。
> 这三道题覆盖的是面试真正会考的那部分几何。

---

## 核心定义

| 术语 | 定义 |
|---|---|
| **Axis-aligned（轴对齐）** | 矩形的边平行于坐标轴 ⟹ 只需比较 x 和 y 两个独立的一维区间 |
| **Bounding Box（最小外接矩形）** | 包含所有目标点的最小轴对齐矩形，由 `minR/maxR/minC/maxC` 确定 |
| **Rectangle Intersection（矩形交集）** | 二维交集 = x 方向区间交集 **×** y 方向区间交集 |
| **Inclusion–Exclusion（容斥）** | `\|A ∪ B\| = \|A\| + \|B\| − \|A ∩ B\|` |
| **Coordinate Hashing（坐标哈希）** | `Counter[(x, y)]`，**必须是频率表，不能是 Set** |
| **Geometric Counting（几何计数）** | 用乘法原理把「顶点选择」的组合数乘起来 |
| **Slope Normalization（斜率归一化）** | 用 `gcd` 约简的**整数方向向量**代替浮点斜率 |

## 三个决定性观察

### ① 轴对齐让二维问题退化成两个独立的一维问题

```python
# 矩形交集：x 和 y 各自算一维区间交集，再相乘
w = max(0, min(ax2, bx2) - max(ax1, bx1))
h = max(0, min(ay2, by2) - max(ay1, by1))
intersection = w * h
```

**为什么交集的左边界是 `max(两个左边界)`、右边界是 `min(两个右边界)`？**
点 `x` 同时在两个矩形的 x 范围内 ⟺ `ax1 <= x <= ax2` 且 `bx1 <= x <= bx2`
⟺ `max(ax1,bx1) <= x <= min(ax2,bx2)`。
这**就是**区间交集公式 —— 和
[14-intervals 的 LC-0986](<../../14-intervals (区间)/02 - 双指针区间交集与多路合并/01 - 两个有序区间序列求交集/01 - LC-0986 - Interval List Intersections (学习索引 · 实体在 02-two-pointers)>)
的 `max(start) / min(end)` 完全是同一件事。

**为什么要 `max(0, ...)`？**
两矩形在 x 方向分离时差值是**负数**。负「宽度」没有几何意义；
不夹到 0 的话「减去交集」会变成「加上一个正数」⟹ **答案偏大**。

### ② `+1` 还是不 `+1` —— 本层最容易差一整圈的地方

| 在算什么 | 公式 | `[1,1]` 代表 |
|---|---|---|
| **离散格子个数** | `max - min + 1` | **1 个格子**（面积 1） |
| **连续长度 / 面积** | `max - min` | **一个点**（面积 0） |

| 题 | 哪一类 | 公式 |
|---|---|---|
| [LC-3195](<./01 - Bounding Box 与矩形交集/01 - LC-3195 - Find the Minimum Area to Cover All Ones I>) | **数格子** | `(maxR-minR+1) * (maxC-minC+1)` ✅ **有 +1** |
| [LC-0223](<./01 - Bounding Box 与矩形交集/02 - LC-0223 - Rectangle Area>) | **量面积** | `(x2-x1) * (y2-y1)` ❌ **无 +1** |

> **同一个「矩形」，一个在数格子，一个在量长度。**
> LC-3195 漏 `+1` 答案偏小，LC-0223 多 `+1` 答案偏大。
> **自检**：你的公式对 `[1,1]` 给 1 还是 0？

### ③ 几何计数必须用**频率表**，不能用 Set

LC-2013 的 `count(query)` 要数「能和查询点组成轴对齐正方形的三元组个数」。
若另外三个顶点的出现次数分别是 `a`、`b`、`c`，
它们的组合数贡献是 **`a × b × c`**（乘法原理）。

**用 Set 会怎样？** 同一个点被 `add` 两次，Set 里只有一份
⟹ 组合数全按 1 算 ⟹ **答案偏小**。

**具体例子**：`add([0,0])` 两次、`add([0,2])` 一次、`add([2,0])` 一次，
查询 `[2,2]`。正方形的另外三个顶点是 `(0,0)`、`(0,2)`、`(2,0)`
⟹ 贡献 `2 × 1 × 1 = 2`，不是 1。

## 核心不变量

**Bounding Box（LC-3195）**：
> 扫描过程中 `minR/maxR/minC/maxC` 始终是「已见过的所有 1」的极值
> ⟹ 扫完一遍即得全局外接矩形。

**矩形交集（LC-0223）**：
> `w` 和 `h` 恒为**非负**（靠 `max(0, ...)`）
> ⟹ `w * h` 恒为合法面积，容斥公式在任何相对位置下都成立。

**坐标计数（LC-2013）**：
> `counts[(x,y)]` 恒等于该点被 `add` 的次数
> ⟹ 任意时刻的 `count()` 都基于当前完整的点集。

**共线计数（LC-0149）**：
> 以点 `i` 为基准时，`dirs[(dx,dy)]` 恒等于
> 「从 `i` 出发、方向规范化为 `(dx,dy)` 的点数」
> ⟹ 该方向上的直线包含 `dirs[...] + 1` 个点（`+1` 是 `i` 自己）。

## 简短正确性证明

### LC-0223：为什么要减去重叠面积（容斥）

`Area(A) + Area(B)` 把两矩形**都**覆盖的区域算了**两次**。
容斥原理：减一次就回到「每块只算一次」。∎

**为什么只在边界相接时交集面积为 0？**
若 `ax2 == bx1`（A 的右边贴着 B 的左边），`w = ax2 - bx1 = 0` ⟹ 面积 0。
几何上两矩形共享一条**线段**，线段面积确实是 0
—— **公式自然给出 0，不需要额外的 if。**

**如何处理负坐标？** 完全不需要特殊处理 —— 公式只有 `min`/`max`/减法。

### LC-2013：为什么正方形必须轴对齐、为什么枚举对角顶点

题目只要求**轴对齐**正方形 ⟹ 四个顶点形如
`(x1,y1), (x1,y2), (x2,y1), (x2,y2)` 且 `|x2-x1| == |y2-y1|`。

给定查询点 `(qx, qy)`，枚举**对角顶点** `(px, py)`：
- 对角顶点确定后，另外两个顶点**唯一确定**为 `(qx, py)` 和 `(px, qy)`
- 所以只需要 O(已有点数) 次枚举，不需要枚举三个点

**为什么宽高的绝对值必须相等？** 正方形的定义。
```python
if abs(px - qx) != abs(py - qy):  continue
```

**为什么零边长不构成合法正方形？**
```python
if px == qx or py == qy:  continue      # ! 退化成线段或点
```
边长 0 的「正方形」不是正方形；题目也明确要求正面积。

**计数**：贡献 `counts[(px,py)] × counts[(qx,py)] × counts[(px,qy)]`（乘法原理）。
注意**查询点自己不计入**（题目说查询点可能不在点集里）。∎

### LC-0149：为什么枚举基准点就不会漏

设最优直线 `L` 上有 `m >= 2` 个点。外层枚举到 `L` 上任意一点 `i` 时，
`L` 上其余 `m-1` 个点相对 `i` 的方向**完全相同** ⟹ 落进同一个桶
⟹ 该桶计数 `m-1` ⟹ 答案 `(m-1)+1 = m`。∎

**为什么只需要「方向」而不需要截距？**
所有向量都从**同一个基准点** `i` 出发 ⟹ 过定点 + 定方向 = 唯一一条直线。

**为什么方向相反必须视为同向？**
`(1,2)` 和 `(-1,-2)` 是同一条直线的两个方向。
**反例** `[(0,0),(1,1),(-1,-1)]`：以 `(0,0)` 为基准，不统一符号 ⟹ 两个桶各 1
⟹ 答案 2，**正确答案是 3**（三点共线）。

**统一符号规则**：
```python
if dx < 0 or (dx == 0 and dy < 0):
    dx, dy = -dx, -dy
```
水平线 → `(1,0)`；垂直线 → `(0,1)`；斜率 `2/3` → `(3,2)`。**每条直线唯一表示。**

## Python 模板

### Bounding Box（LC-3195）

```python
minR = minC = float('inf'); maxR = maxC = -1
for r in range(m):
    for c in range(n):
        if grid[r][c] == 1:
            minR, maxR = min(minR, r), max(maxR, r)
            minC, maxC = min(minC, c), max(maxC, c)
return (maxR - minR + 1) * (maxC - minC + 1)      # ! 数格子 ⟹ 有 +1
```
**O(m·n)** 时间、O(1) 空间。

### Template 9：Rectangle Intersection + 容斥（LC-0223）

```python
area_a = (ax2 - ax1) * (ay2 - ay1)                # ! 量面积 ⟹ 无 +1
area_b = (bx2 - bx1) * (by2 - by1)
w = max(0, min(ax2, bx2) - max(ax1, bx1))         # ! max(0,..) 夹住负宽
h = max(0, min(ay2, by2) - max(ay1, by1))
return area_a + area_b - w * h
```
**O(1)** 时间与空间。

**只判「是否重叠」**（正面积）：
```python
overlap = ax1 < bx2 and bx1 < ax2 and ay1 < by2 and by1 < ay2    # ! 严格小于
```

### Template 10：Coordinate Hash Map Counting（LC-2013）

```python
class DetectSquares:
    def __init__(self):
        self.counts = Counter()                    # ! 必须是频率表，不能是 set
    def add(self, point):
        self.counts[tuple(point)] += 1
    def count(self, point):
        qx, qy = point
        total = 0
        for (px, py), k in self.counts.items():    # ! 枚举对角顶点
            if abs(px - qx) != abs(py - qy):  continue   # ! 宽高绝对值必须相等
            if px == qx or py == qy:          continue   # ! 零边长不合法
            total += k * self.counts[(qx, py)] * self.counts[(px, qy)]   # ! 乘法原理
        return total
```
`add` **O(1)**，`count` **O(P)**（`P` = 不同点数）。

### Slope Normalization + GCD（LC-0149）

```python
best = 2
for i in range(n):
    x1, y1 = points[i]
    dirs = defaultdict(int)
    for j in range(i + 1, n):
        dx, dy = points[j][0] - x1, points[j][1] - y1
        g = gcd(abs(dx), abs(dy))                  # ! 约简到最简整数比
        dx, dy = dx // g, dy // g
        if dx < 0 or (dx == 0 and dy < 0):         # ! 统一符号
            dx, dy = -dx, -dy
        dirs[(dx, dy)] += 1
        best = max(best, dirs[(dx, dy)] + 1)       # ! +1 是基准点自己
```
**O(n² log V)** 时间、O(n) 空间。
⚠️ `gcd(0,0) == 0` ⟹ 允许重复点时必须先拦下 `dx == dy == 0`。

**判三点共线用叉积**（无除法、无 gcd、无精度问题）：
```python
(y2 - y1) * (x3 - x1) == (y3 - y1) * (x2 - x1)
```
但用它枚举所有三元组是 **O(n³)** —— 它的正确用法是**验证**，不是主算法。

## 常见错误与反例

| 错误做法 | 反例 | 结果 |
|---|---|---|
| LC-0223 忘记 `max(0, ...)` | 两矩形分离 | 负交集 ⟹ 「减」变「加」⟹ 偏大 ❌ |
| LC-0223 加了 `+1` | 任意 | 面积整体偏大 ❌ |
| LC-3195 漏了 `+1` | `[[1]]` | 得 0，正确 1 ❌ |
| LC-2013 用 Set 存点 | 同一点 `add` 两次 | 组合数按 1 算 ⟹ 偏小 ❌ |
| LC-2013 不检查 `abs(dx) == abs(dy)` | 任意矩形（非正方形） | 把长方形也数进去 ❌ |
| LC-2013 不排除零边长 | 查询点与对角点同行 | 把退化图形数进去 ❌ |
| LC-2013 枚举**三个**顶点 | — | O(P³)，而枚举对角顶点只需 O(P) ❌ |
| LC-0149 用**浮点**斜率 | 垂直线 / 精度边界 | 除零或两条直线被当成一条 ❌ |
| LC-0149 不统一方向符号 | `[(0,0),(1,1),(-1,-1)]` | 得 2，正确 **3** ❌ |
| LC-0149 不约简（直接用 `(dx,dy)`） | `[(0,0),(1,2),(2,4)]` | `(1,2)` 和 `(2,4)` 分两个桶 ⟹ 得 2，正确 3 ❌ |
| LC-0149 没拦 `gcd(0,0)` | 允许重复点的变体 | `ZeroDivisionError` ❌ |
| LC-0149 用 O(n³) 叉积枚举 | `n = 300` | 2700 万次，边界超时 ❌ |
| 用 `sqrt` 比距离 | 任意 | 浮点误差；应比**距离的平方** ❌ |
