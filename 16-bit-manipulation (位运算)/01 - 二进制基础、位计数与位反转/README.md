# Level 1 · 01 — 二进制基础、位计数与位反转（Bit Basics / Popcount / Reverse Bits）

> **本层的统一目标：把一个整数当成「一串位」来读、来数、来重排。**
> 这是整个专题的地基 —— 后面三层的所有技巧都建立在「会单独操作某一位」之上。

---

## 核心定义

| 术语 | 定义 |
|---|---|
| **Popcount（二进制置位数量）** | 一个数里 1 的个数，又叫 Hamming Weight |
| **Lowest Set Bit（最低有效置位）** | 从低位看第一个为 1 的位 |
| **Fixed-width Integer（固定宽度整数）** | 宽度由题目给定（如「32 位无符号」），**前导零也是有效位** |
| **Counting Bits DP** | 用 `dp[i >> 1]` 递推出 `dp[i]`，一遍算出 `0..n` 的全部 popcount |

---

## 三个决定性观察

### ① `x & (x - 1)` 恰好清掉**最低位的那个 1**

```
x        = 0b1011000
x - 1    = 0b1010111      ← 最低位 1 变 0，它右边全变 1
x & (x-1)= 0b1010000      ← 最低位的 1 被清掉，其余不变
```

**证明**：设 `x` 最低位 1 在第 `k` 位，则 `x = A·2^(k+1) + 2^k`（低 `k` 位全 0）。
`x - 1 = A·2^(k+1) + (2^k - 1)`，即第 `k` 位变 0、低 `k` 位全 1。
AND 之后：高位 `A` 不变（两者相同），第 `k` 位 `1 & 0 = 0`，
低 `k` 位 `0 & 1 = 0` ⟹ 恰好只清掉了第 `k` 位。∎

**两个直接推论**：
- **Popcount 的循环次数 = 1 的个数**（不是 32）⟹ **O(popcount)**
- **2 的幂 ⟺ 只有一个 1 ⟺ `x & (x-1) == 0`**（且 `x > 0`）

### ② `x & (-x)` 只**保留**最低位的 1（和①正好相反）

| 表达式 | 作用 |
|---|---|
| `x & (x - 1)` | **清掉**最低位 1 |
| `x & (-x)` | **只保留**最低位 1 |

```
x        = 0b1011000
x & (-x) = 0b0001000
```
**证明**：补码 `-x == ~x + 1`。`-x` 等于「最低位 1 右边保持（全 0）、
最低位 1 本身保持、更高位全部取反」⟹ AND 之后高位全灭。∎

**这两个式子是全专题最容易记混的一对。**
①用于 Popcount 和 2 的幂；②用于分组区分位（[LC-0260](<../02 - XOR 不变量与二进制算术/01 - XOR 抵消与缺失元素/03 - LC-0260 - Single Number III>)）和树状数组 lowbit。

### ③ 固定宽度题目里，**宽度本身是题意的一部分**

LC-0190 要反转一个 **32 位无符号**整数。所以：

```python
for _ in range(32):                 # ! 必须恰好 32 次
    res = (res << 1) | (n & 1)
    n >>= 1
```

**为什么不能写 `while n`？**
`n = 1` 时 `while n` 只转 1 次 ⟹ 返回 1。
但正确答案是 `2^31 = 2147483648`（1 被推到了最高位）。
**前导零也要参与反转** —— 它们决定了那个 1 最终落在哪。

## 核心不变量

**Brian Kernighan Popcount**：
> 每次迭代后 `x` 中 1 的个数**恰好减少 1**，且其余位不变
> ⟹ 迭代次数 = 原始 popcount。

**Counting Bits DP（LC-0338）**：
> `dp[i]` 恒等于 `i` 的 popcount。
> 递推 `dp[i] = dp[i >> 1] + (i & 1)` 的含义是
> 「`i` 的 1 的个数 = 去掉最低位后的 1 的个数 + 最低位是不是 1」。

**Fixed-width Reverse（LC-0190）**：
> 第 `k` 轮结束时，`res` 的低 `k` 位恰好是 `n` 的低 `k` 位的**逆序**。

---

## 为什么用这些位操作（而不是转字符串）

| 做法 | Popcount 复杂度 | 为什么位运算更好 |
|---|---|---|
| `bin(x).count('1')` | O(32)，但要**建字符串** | 可读，面试可以提，但有分配开销 |
| 逐位 `x >> i & 1` | **固定 O(32)** | 和 1 的个数无关 |
| **`x &= x - 1`** | **O(popcount)** | 稀疏数据上快得多；而且这个技巧本身能迁移 |
| `x.bit_count()` | O(32)，C 实现 | Python 3.10+，最快，但面试要先说出原理 |

⚠️ **`bin(x)` 对负数是错的**：`bin(-5) == '-0b101'`（带负号，不是补码）
⟹ 必须先 `x & 0xFFFFFFFF`。

---

## 简短正确性证明

### Counting Bits DP 为什么对

对任意 `i >= 1`，把 `i` 的二进制写成 `(i >> 1)` 后面再接一位 `(i & 1)`：
```
i = 0b1011  ⟹  i >> 1 = 0b101，  i & 1 = 1
```
`i` 的所有 1 = 「`i >> 1` 的所有 1」+「最低位是否为 1」
⟹ `popcount(i) = popcount(i >> 1) + (i & 1)`。
因为 `i >> 1 < i`，按 `i` 升序计算时 `dp[i >> 1]` 已就绪 ⟹ **O(n)** 一遍完成。∎

**另一个等价递推**：`dp[i] = dp[i & (i - 1)] + 1`
（由观察①：清掉一个 1 之后的 popcount 再 +1）。

### 2 的幂判定为什么需要 `x > 0`

`x = 0`：`0 & (0 - 1) = 0 & -1 = 0` ⟹ **会误判为真**。
负数在 Python 的无限位补码下也会给出意外结果。
⟹ **`x > 0 and x & (x - 1) == 0`，`x > 0` 不能省。**∎

## Python 核心模板

```python
# ① Popcount —— Brian Kernighan（O(popcount)）
def hammingWeight(n):
    cnt = 0
    while n:
        n &= n - 1              # ! 每次清掉一个最低位 1
        cnt += 1
    return cnt

# ② 判断 2 的幂
def isPowerOfTwo(n):
    return n > 0 and n & (n - 1) == 0      # ! n > 0 不能省

# ③ Counting Bits DP —— 一遍算出 0..n 的全部 popcount
def countBits(n):
    dp = [0] * (n + 1)
    for i in range(1, n + 1):
        dp[i] = dp[i >> 1] + (i & 1)       # ! 或 dp[i & (i-1)] + 1
    return dp

# ④ 固定宽度反转（32 位）
def reverseBits(n):
    res = 0
    for _ in range(32):                    # ! 固定 32 次，不是 while n
        res = (res << 1) | (n & 1)
        n >>= 1
    return res

# ⑤ 单位操作
x >> i & 1            # 读第 i 位
x | (1 << i)          # 置 1
x & ~(1 << i)         # 清 0
x ^ (1 << i)          # 翻转
```

## 典型反例

| 错误做法 | 反例 | 结果 |
|---|---|---|
| `isPowerOfTwo` 省掉 `n > 0` | `n = 0` | `0 & -1 == 0` ⟹ 误判为真 ❌ |
| `isPowerOfTwo` 不处理负数 | `n = -4` | Python 无限位补码下结果不可靠 ❌ |
| LC-0190 用 `while n` | `n = 1` | 得 1，正确是 `2147483648` ❌ |
| LC-0190 循环 31 次 | 任意 | 整体错位一位 ❌ |
| LC-0338 对每个数单独算 popcount | `n = 10^5` | O(n log n)，DP 只需 O(n) ⚠️ |
| 用 `bin(x).count('1')` 处理负数 | `x = -5` | `bin(-5) == '-0b101'`，不是补码 ❌ |
| 把 `x & (x-1)` 和 `x & (-x)` 记反 | LC-0260 的区分位 | 分组逻辑整个错 ❌ |
| 逐位扫描负数 | `x = -1` | Python 里有无限多个符号位 ⟹ 死循环 ❌ |

## 容易混淆的 Pattern

### `x & (x - 1)` vs `x & (-x)`

| | `x & (x - 1)` | `x & (-x)` |
|---|---|---|
| 作用 | **清掉**最低位 1 | **只保留**最低位 1 |
| `0b1011000` → | `0b1010000` | `0b0001000` |
| 典型用途 | Popcount、判 2 的幂 | 区分位分组、树状数组 lowbit |
| 本专题的题 | LC-0191、LC-0231 | LC-0260 |

### Popcount 的三种复杂度

- `while x: x &= x-1` ⟹ **O(popcount)**，稀疏数据最快
- `for i in range(32)` ⟹ **固定 O(32)**，和数据无关
- `bin(x).count('1')` ⟹ O(32) + 字符串分配，**对负数错**

### 固定宽度 vs 任意宽度

| | 固定宽度（LC-0190） | 任意宽度（LC-0191 的 Kernighan 版） |
|---|---|---|
| 循环 | **固定 32 次** | `while x`（次数 = popcount） |
| 前导零 | **是有效位**，参与运算 | 无影响 |
| 负数 | 必须先 `& MASK` | `x > 0` 时安全 |
