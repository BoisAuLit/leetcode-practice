# Level 1 · 03 — Bitwise Subarray 与位聚合（Bitwise Aggregation over Subarrays）

> **本层的统一目标：对「所有子数组」做 OR / AND 聚合，而不枚举 O(n²) 个子数组。**
> 唯一的武器是一个计数论证：**OR 单调递增 + 只有 32 位可变 ⟹ 状态数是 O(32)。**

---

## 核心定义

| 术语 | 定义 |
|---|---|
| **Bitwise OR Aggregation** | 以每个右端点结尾的所有子数组 OR 值的集合 |
| **OR 的单调性** | 往子数组里加元素，OR 值**只会变大或不变**（只置 1，永不清 0） |
| **AND 的单调性** | 往子数组里加元素，AND 值**只会变小或不变**（只清 1，永不置 1） |
| **按位贡献（Bit Contribution）** | 对每一位独立统计「最近一次出现 1 的位置」 |

---

## 三个决定性观察

### ① 以固定右端点结尾的子数组，**不同的 OR 值最多只有 O(32) 个**

设 `S(i) = { OR(nums[j..i]) : 0 <= j <= i }`（以 `i` 结尾的所有子数组 OR 值）。

**关键**：固定 `i`，当 `j` 从 `i` 往左移动时，OR 值**单调不减**
（加入更多元素只会置更多位为 1）。
而一个 32 位整数的 OR 值每次「变大」至少要**新增一个为 1 的位**
⟹ 最多变大 32 次 ⟹ **`|S(i)| <= 33`**。∎

于是：
```python
cur = {0}
for x in nums:
    cur = {y | x for y in cur} | {x}      # ! 集合大小恒 <= 33
    ans |= cur                             # 或做其他统计
```
**总复杂度 O(32n)，而不是 O(n²)。** 📍 LC-0898

### ② 最大 Bitwise AND **就是数组的最大值**

AND 只会让值变小或不变（只清位）⟹ 任何子数组的 AND `<=` 其中任一元素
`<= max(nums)`。

而**长度为 1 的子数组** `[max(nums)]` 的 AND 恰好等于 `max(nums)`
⟹ **上界可达** ⟹ 最大 AND = `max(nums)`。∎

**推论**：要「最大 AND 的最长子数组」，只能由**全是 `max` 的连续段**构成
（一旦混进一个更小的数，AND 就会掉下来）
⟹ **题目退化成「求最大值的最长连续段」**，和位运算几乎无关。📍 LC-2419

> **这是本层最漂亮的一次「题目退化」** ——
> 看懂单调性之后，位运算题变成了一道一年级扫描题。

### ③ 「最近一次出现 1 的位置」能支持「最短的最大 OR 子数组」

LC-2411 要对每个起点 `i` 求「最短的 `j`，使 `OR(nums[i..j])` 达到
`OR(nums[i..n-1])`（即从 `i` 开始能取到的最大 OR）」。

**从右往左扫**，维护 `last[b]` = 「第 `b` 位最近一次出现 1 的下标」：
```python
last = [0] * 32
for i in range(n - 1, -1, -1):
    for b in range(32):
        if nums[i] >> b & 1:
            last[b] = i                    # ! 更新这一位的最近位置
    # ! 要凑齐所有能凑到的位，必须伸到最远的那个 last[b]
    ans[i] = max(1, max(last[b] for b in range(32) if last[b] > 0) - i + 1)
```
**为什么对？** 从 `i` 出发能取到的最大 OR 的每一个为 1 的位，
都必须在 `[i, j]` 内**至少出现一次**。
要同时凑齐所有这些位，`j` 必须 `>=` 它们各自的「最近出现位置」的最大值。∎

**O(32n)** 时间、O(32) 空间。

---

## 核心不变量

**OR 状态集合（LC-0898）**：
> 处理完第 `i` 个元素后，`cur` 恰好等于
> 「所有以 `i` 结尾的子数组的 OR 值」的集合，且 `|cur| <= 33`。

**最大值连续段（LC-2419）**：
> 扫描时 `run` 恒等于「当前以 `i` 结尾的、全部等于 `max` 的连续段长度」。

**最近位置表（LC-2411）**：
> 从右往左扫到 `i` 时，`last[b]` 恒等于
> 「下标 `>= i` 的元素中，第 `b` 位为 1 的最小下标」（不存在则为哨兵）。

---

## 为什么用这些位操作

### 为什么 OR 的状态数有界，但「所有子数组的和」没有？

**因为 OR 是幂等 + 单调的**：`x | x == x`，且加元素只能变大。
一个 32 位数最多「变大」32 次 ⟹ 状态有界。

**和（sum）既不幂等也不单调有界** ⟹ 不同的子数组和可以有 O(n²) 个
⟹ 这个技巧**只适用于 OR / AND / GCD 这类「单调 + 取值有界」的聚合**。

> **可迁移性**：同样的论证适用于
> **子数组 GCD**（GCD 单调不增，且每次变化至少减半 ⟹ O(log V) 个状态）
> 和子数组 AND。**这是本层真正值得带走的东西。**

### 为什么 AND 不需要维护状态集合？

因为 LC-2419 只问**最大** AND，而观察②直接给出了答案 = `max(nums)`
⟹ 不需要枚举状态。
若题目问「所有子数组 AND 的不同取值个数」，就要像 OR 一样维护 O(32) 状态集合。

---

## 简短正确性证明

### `|S(i)| <= 33`

`S(i)` 中的值按 `j` 递减排列是**单调不减**的序列。
相邻两个值若不等，后者必须比前者**多至少一个为 1 的位**。
32 位整数最多有 32 个位 ⟹ 严格递增的次数 `<= 32`
⟹ 不同取值 `<= 33`（含起始值）。∎

### 最大 AND = `max(nums)`

**上界**：对任意子数组 `A`，`AND(A) <= min(A) <= max(nums)`。
**可达**：取单元素子数组 `[max(nums)]`，其 AND 就是 `max(nums)`。
⟹ 最大值可达，即为答案。∎

**最长段**：若子数组 `A` 的 `AND(A) == max(nums)`，
则 `A` 中每个元素 `x` 满足 `x & ... == max` ⟹ `max <= x`（AND 是子集）
且 `x <= max` ⟹ `x == max` ⟹ **`A` 全由 `max` 构成**。∎

## Python 核心模板

```python
# ① 所有子数组的不同 OR 值（LC-0898）—— 状态集合滚动
def subarrayBitwiseORs(nums):
    ans, cur = set(), set()
    for x in nums:
        cur = {y | x for y in cur} | {x}     # ! |cur| <= 33，不会爆
        ans |= cur
    return len(ans)
# O(32n) 时间、O(32n) 空间（ans 最多 O(32n) 个不同值）

# ② 最大 AND 的最长子数组（LC-2419）—— 退化成最大值连续段
def longestSubarray(nums):
    mx = max(nums)                           # ! 最大 AND 就是最大值
    best = run = 0
    for x in nums:
        run = run + 1 if x == mx else 0      # ! 只统计全是 mx 的连续段
        best = max(best, run)
    return best
# O(n) 时间、O(1) 空间

# ③ 最短的最大 OR 子数组（LC-2411）—— 每位的「最近出现位置」
def smallestSubarrays(nums):
    n = len(nums)
    last = [-1] * 32
    ans = [1] * n
    for i in range(n - 1, -1, -1):
        for b in range(32):
            if nums[i] >> b & 1:
                last[b] = i
        far = max([p for p in last if p >= 0], default=i)
        ans[i] = max(1, far - i + 1)
    return ans
# O(32n) 时间、O(32) 空间
```

## 时间与空间复杂度

| 题 | 时间 | 空间 | 注意 |
|---|---|---|---|
| LC-0898 | **O(32n)** | O(32n) | ⚠️ **不是 O(n²)** —— 状态集合有界是全部关键 |
| LC-2411 | **O(32n)** | **O(32)** | 每位一个指针 |
| LC-2419 | **O(n)** | **O(1)** | ⚠️ **不是 O(32n)** —— 退化成纯扫描 |

> **三道题的复杂度各不相同**，不要一律写 O(32n)。
> LC-2419 因为题目退化，**连位运算都不需要了**。

## 典型反例

| 错误做法 | 反例 | 结果 |
|---|---|---|
| LC-0898 枚举所有 O(n²) 子数组 | `n = 5×10^4` | 25 亿次 ⟹ TLE ❌ |
| LC-0898 把 `cur` 当成 list 不去重 | 任意 | 规模爆炸（去重是「状态数 O(32)」的前提）❌ |
| LC-0898 忘了 `| {x}`（单元素子数组） | `[1]` | 漏掉长度 1 的子数组 ❌ |
| **LC-2419 以为要维护 AND 状态集合** | 任意 | 能对但完全多余 —— 答案就是 `max(nums)` ⚠️ |
| LC-2419 统计「含 max 的段」而非「全是 max 的段」 | `[1,2,3,3,2,2]` | `max=3`，正确答案 2；若把 `2` 也算进段会得 4 ❌ |
| LC-2411 从左往右扫 | 任意 | 「最近出现」必须从右往左才有意义 ❌ |
| 把 OR 的状态有界论证套到**子数组和** | 任意 | 和既不幂等也不单调有界 ⟹ O(n²) 个状态 ❌ |
| 位数写成 `range(31)` 或 `range(30)` | 含 `2^31` 级别的数 | 漏掉最高位 ❌ |

## 容易混淆的 Pattern

### OR 聚合 vs AND 聚合

| | **OR** | **AND** |
|---|---|---|
| 单调性 | 加元素 ⟹ **只增** | 加元素 ⟹ **只减** |
| 最大值在哪 | 整个数组的 OR | **单个最大元素**（所以 LC-2419 退化了） |
| 最小值在哪 | 单个最小元素 | 整个数组的 AND |
| 状态数 | O(32) | O(32)（同理） |
| 本层的题 | LC-0898、LC-2411 | LC-2419 |

### 「状态数有界」适用 / 不适用的聚合运算

| 聚合 | 状态数 | 能用吗 |
|---|---|---|
| **OR** | O(32) | ✅ |
| **AND** | O(32) | ✅ |
| **GCD** | O(log V)（每次至少减半） | ✅ **同一个论证** |
| 和（sum） | O(n) | ❌ 既不幂等也不有界 |
| 最大值 | O(n) | ❌（但有单调栈等别的办法） |

> **判断标准：这个运算是不是「幂等 + 单调 + 取值空间小」？**
> 三者齐备 ⟹ 状态数有界 ⟹ 可以滚动集合。

### 和 Level 02 的 Range AND 不是一回事

| | [LC-0201 Range AND](<../02 - XOR 不变量与二进制算术/03 - Range AND 与共同高位前缀/01 - LC-0201 - Bitwise AND of Numbers Range>) | **本层 LC-2419** |
|---|---|---|
| 对象 | **连续整数** `[left, right]` 的 AND | **数组的子数组**的 AND |
| 答案 | 公共高位前缀 | `max(nums)` |
| 技巧 | 同时右移 | 单调性 ⟹ 退化成扫描 |

**两者都叫「Range AND」但毫无关系。** 一个是值域区间，一个是数组区间。
