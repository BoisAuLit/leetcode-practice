# Level 1 · 01 最近更大元素与跨度

## 核心定义
给定一个序列，为每个元素找**最近的、比它更大（或更小）的邻居**，
或者统计「连续满足某条件的一段有多长」。这是整个单调栈体系的入口。

## 决定性观察
1. 一个元素的答案，是在**另一个元素到来时**被确定的 —— 不是自己算出来的。
2. 当 `x > nums[j]` 时，j 的答案就是 x；而且 j 以后再也挡不住任何人（x 更大、更靠后），
   所以可以把 j **永久删除**。这就是单调性的来源，不是「为了有序而有序」。
3. 存下标还是存值：要算距离（739 的天数差）、要写回 res、或元素可能重复 → 存下标。

## Loop Invariant（循环不变量）
处理完下标 i 之后：栈中保存的是 `0..i` 里**所有还没拿到答案**的下标，
且它们对应的值从栈底到栈顶**单调不增**。

## Push / Pop 规则
- Pop：`nums[stack[-1]] < cur`（严格小于）→ 找的是「严格更大」。相等不弹。
- Push：每个下标恰好一次（LC-0503 的第二轮例外，第二轮只弹不压）。

## 正确性
栈单调不增 ⟹ 当 cur 弹出栈顶 j 时，j 与 i 之间的所有元素都 `<= nums[j] < cur`，
所以 **cur 是 j 右边第一个严格更大的元素**。

## 典型模板
```python
res, stack = [-1] * n, []
for i, x in enumerate(nums):
    while stack and nums[stack[-1]] < x:
        res[stack.pop()] = x          # 也可以写 i - stack.pop() 得到距离
    stack.append(i)
```

| 01/03 | LC-0503 Next Greater Element II | P1 | 环形：跑 2n 轮 + `i % n`，**第二轮只弹不压**（否则栈里出现重复下标） |
| 02/01 | LC-0901 Online Stock Span | P0 | 方向反过来：当前元素**汇总过去**；`(price, span)` 状态压缩；`<=` 吞等值 |
| 03/01 | LC-0456 132 Pattern | P1 | 从**右往左**扫；栈外一个 `third` 记住「被弹出的最大值」 |

## 常见错误
- LC-0739 存了温度值而不是下标 → 算不出天数差。
- LC-0503 第二轮还往栈里压 → res 被写两次，结果错。
- LC-0901 用 `<` 而不是 `<=` → 相同价格没被合并进跨度。
- LC-0901 宣称单次 `next()` 是 O(1) → 错，单次最坏 O(n)，**摊还** O(1)。
- LC-0456 从左往右扫 → 无法同时握住「3」和「被它弹掉的 2」。

## 复习时的 Pattern Recognition
> 「右边第一个更大/更小」「下一个比今天暖的日子」「连续多少天不超过今天」
> 「i<j<k 且值呈 1-3-2 形状」 → 一律先想单调栈，而不是双重循环。
