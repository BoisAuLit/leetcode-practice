# Strict vs Non-strict Comparison Cheat Sheet（严格 / 非严格比较）

> 重复元素是单调栈最大的 bug 来源。下表按题列出**本仓库采用的约定**。
> 原则：同一道题里的符号必须前后一致，不能从不同模板里东拼西凑。

| 题 | 要找的关系 | Pop 条件 | 相等时怎么办 | 为什么 |
|---|---|---|---|---|
| LC-0496 Next Greater I | 严格更大 | `nums[stack[-1]] < cur` | 不弹 | 题目要「更大」，相等不算 |
| LC-0739 Daily Temperatures | 严格更高温度 | `T[stack[-1]] < cur` | 不弹 | 同温不算 warmer day |
| LC-0503 Next Greater II | 严格更大 | `nums[stack[-1]] < cur` | 不弹 | 同 496；注意第二轮只弹不压 |
| LC-0901 Online Stock Span | **小于等于**都计入跨度 | `stack[-1].price <= price` | **弹（吞掉）** | 题面明确「价格 ≤ 今天」都算连续 |
| LC-0084 Histogram | 右边第一个更矮 | `heights[stack[-1]] > cur` | 不弹 | 等高柱子被同一个矩形覆盖，面积不会算漏 |
| LC-0907 Σ subarray min | 一严格一非严格 | `arr[stack[-1]] > cur` | 不弹 | 只有**最左边**的相等元素认领整串，避免重复计数 |
| LC-2104 Σ subarray range | 同上，max/min 各一套 | max 用 `<`，min 用 `>` | 不弹 | 两侧 Tie Breaking 必须各自自洽 |
| LC-1856 Min-Product | 同 907 | `nums[stack[-1]] > cur` | 不弹 | 求 max 不怕重复，但保持模板统一 |
| LC-0402 Remove K Digits | 严格更大才换 | `stack[-1] > x` | 不弹 | 相等换了没收益，还白耗删除预算 |
| LC-0316 Remove Dup Letters | 严格更大才换 | `stack[-1] > c` | 不弹 | 同上，另加「以后还会出现」判据 |
| LC-1673 Most Competitive | 严格更大才换 | `stack[-1] > x` | 不弹 | 同上，另加「后面够不够补满」判据 |
| LC-0239 Sliding Window Max | 支配 | `nums[dq[-1]] <= x` | **弹** | 保留或移除等值候选都正确，只要队首始终有效；这里统一用 `<=` |
| LC-1438 两个 Deque | 支配 | max 用 `<=`，min 用 `>=` | 弹 | 同上，前后一致即可 |
| LC-1762 Ocean View | **严格大于**后缀最大值 | — | 无海景 | 右边有等高楼也会挡住视线 |
| LC-0853 Car Fleet | 到达时间 **<=** 就合并 | `t_cur <= t_fleet` | **合并** | 恰好在终点追上，仍算同一车队 |
| LC-0456 132 Pattern | 严格 | `stack[-1] < x` | 不弹 | 要求 `nums[i] < nums[k] < nums[j]` 三者严格 |

## 必跑的小用例

| 输入 | 用在哪 | 期望 |
|---|---|---|
| `[2,2]` | 907 | 6（`[2],[2],[2,2]` 的 min 之和 = 2+2+2） |
| `[2,2,2]` | 907 | 12；2104 → 0 |
| `[1,1]` | 907 | 3 |
| `[1,2,1]` | 84 | 3 |
| `[3,1,2,4]` | 907 | 17 |
| `[5,5,4,5]` | 239 (k=2) | `[5,5,5]` |
| `[2,2,2]` | 1673 (k=2) | `[2,2]`（相等不弹） |
| 价格 `[5,5,5]` | 901 | span `1,2,3`（`<=` 吞等值） |

> 这些用例要放进**适用的那道题**去跑，不要把同一组输入硬塞进所有题的 API。
> 本仓库每个新增题目的 `solution.py` 末尾都带随机对拍，已覆盖上述重复值场景。
